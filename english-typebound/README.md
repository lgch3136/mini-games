# 键旅 · TYPEBOUND

一款独立的英文打字冒险。不替换现有游戏，不需要注册、服务器或 API Key。

## 玩法

每个正确字母推进光轨并带来局部波动；完成一个词并按空格释放完整攻击与整词回响。错字不推进、不直接扣血，可以立即重打正确字母。Backspace 允许回退，但重复输入已删除的字母不会刷伤害。所有 26 个字母都用于打字，不与游戏快捷键冲突。

- **冒险旅程**：三章九间战斗，路线选择、七种遗物、四种敌人。完成一轮后可继续远征，强度有上限，不无限加速。
- **静心练习**：相同词库与反馈，无敌人攻击，可慢慢练习。
- **错词回练**：自动记录本机错词；一个词连续两次无错完成后移出错词本。每轮 6–20 个词，不制造战斗压力。
- 词库：直接读取项目 `shared/vocabulary.js`，初级 597、中级 790、高级 942，合计 2,329 个去重分级英文词条。中文释义可隐藏。
- 首领：12 段原创英文短句，分为三个词汇等级；按句中顺序逐词输入，必须写到句末才能完成击杀，完成整句有额外破阵攻击。不是随机单词硬拼成句子。释义按句中语境补充与修正。
- 蓄力：迷途书灵为基础战斗；无错词打断夜蛾蓄力；镜页守卫奖励无错词；首领半血后蓄力加快，有明确预告。
- 路线：普通路回复少量生命；险径敌人更强、可获两份遗物。遗物改变攻击、护盾、恢复、敌人蓄力时间等实际规则。

电脑逐字输入，**空格施法、Enter 护盾、Esc 暂停**。三个整词充满一次护盾。手机默认显示固定 QWERTY 屏幕键盘，也可主动切换系统英文键盘。顶部始终可暂停或结束。

## 统计与练习边界

WPM = 已提交的正确单词字符数（含分隔空格）÷ 5 ÷ 实际战斗分钟。未完成单词不计 WPM，退格重打不会重复增加已提交字数。准确率 = 正确输入次数 / 所有有效英文输入次数；错误后重试仍保留原错键记录。前 3 秒 HUD 显示「—」避免刚开始时的字速跳动，结算保留按公式计算的值。

第一键才开始计时；菜单、地图、奖励、暂停不计入。中文输入法候选、粘贴、组合快捷键和系统按住重复不会变成练习成绩。不上传键盘内容，键盘监听只在本游戏页面有效；本机最多保存 300 个错词和最近 30 次记录。

## 视觉与音频

### 当前：2026-09-28 · 追光练习

- 主视线区域改为平均 WPM、有效练习时间、准确率和已提交词数；取消上方角色对打与无关装饰，不用演出遮挡输入。
- 光点跟随当前正确字母进度，速度变化带来拉伸，落键产生局部涟漪，空格提交产生暖色整词回响。没有输入时光轨静止；重打旧字母不重复刷脉冲。
- 使用从 imagegen 原创封面派生的 256 × 256 透明柔光，结合 Canvas 2D 实时线条。固定 24 个脉冲上限，帧间闭式阻尼，无额外后台动画循环。
- 原战斗、护盾、三系法术、路线、遗物、词库与音频规则保留；血条直接与游戏状态同步。减弱动态模式降低形变与亮度。
- 原创概念封面与游戏截图分开标示。[完整提示词与素材](../docs/light-pass-20260928/ASSETS.md)，[本轮验收](../docs/light-pass-20260928/QA.md)。

### 历史：2026-09-12 绘本版（已不用于当前战斗渲染）

- 2026-09-12 绘本版：imagegen 生成雾林、潮汐藏书、曙光书塔三张统一画风的实际战斗背景，1536 × 1024 WebP 合计约 716 KiB；地图也随章节换景。
- Canvas 2D 分层绘制带表情的旅人、折纸小书灵、夜蛾、书页守卫和首领。入场迈步、站定、眨眼、围巾、翻书、抬臂施法、受击与退场连接成连续动作。
- 按键立即推进文字并点亮书本；字母飞行 190 ms、整词法术飞行 300 ms，抵达时才触发敌人受力、闪光与可见血条变化。弹道起点使用实际书本姿态，命中点跟随角色。逻辑伤害不等待动画，快速输入不被演出锁住。
- 三个无错连词唤醒小书灵，六个进入流光状态，庭院出现花朵与星光；这是连词的视觉和音乐奖励，不悄悄改动战斗伤害。
- 奶油色输入卡片、逐字充能、稳定文字节点、键帽按压与连词弹跳。完整单词提示与敌人蓄力提示分区，避免挡住输入和小屏角色。
- 输入区不震动，不做攻击停帧、全屏闪白或持续镜头晃动。
- 三章原创 Web Audio 配乐分别为 100 / 96 / 108 BPM；输入音跟随当前和弦，连续无错加入分解和弦伴奏。施法、护盾、受击与胜利有各自音色，不使用商业录音。
- 120 Hz 固定模拟；动画有独立时钟和闭式阻尼弹簧。粒子 144、飞行物 80、光线 12、环 16、标签 4，均有上限；数组原位回收。背景与辉光缓存，默认 DPR 上限 1.75，支持节能和减弱动态效果。
- 地图和菜单零 RAF；暂停、失焦、切后台或结束停止 RAF、音频调度与声部。胜利演出结束后也停止，不在奖励界面持续空转。离开销毁输入监听、音频上下文、Canvas 缓存。

```sh
node --test tests/typebound.test.mjs tests/typebound-focus.test.mjs
python3 -m http.server 4173 --bind 127.0.0.1
```

浏览器打开 `tests/typebound-browser.html`。测试工具通过正式页面按钮和普通键盘 / 输入 / Pointer 事件操作，只读取诊断副本，不修改生命、敌人、时钟或进度。单元测试会针对边界构造状态，不能把单元模拟等同于实际游玩。

测试能验证输入、计时、战斗规则、布局、资源释放与性能；不能证明主观趣味性已达到某款商业游戏。手机尺寸在当前 Mac 内置 Browser 模拟，不代替实体手机验收。
