# 键旅 · 绘本版验收

日期：2026-09-12。版本：`20260912-story-r1`。本轮聚焦实际游戏中的动作反馈、画面趣味性和轻量渲染；词库、计分与战斗数值没有重写。

## 视觉与交互检查

在当前 Mac 的 Codex 内置 Browser 中查看了开始页、地图、三章战斗、四类敌人、句子首领、胜利与遗物界面。三张新背景确实用于实际关卡，不以新封面代替游戏画面。

- 角色有眼睛、眨眼、围巾、翻书、分层手臂与迈步；进入后脚部站稳，输入区不随打击抖动。
- 输入当场反馈；法术从实际书本姿态发出，目的地随敌人入场和受力位置移动，命中后才产生敌人闪光与血条变化。
- 连续三个无错词唤醒折纸书灵，六个词进入盛放状态。小书灵、环境花朵和伴奏层提供连续成功的可见奖励；不改变原有伤害计算。
- 修正矮屏中连词状态与完整单词飞出提示重叠的问题。
- 重开测试发现文字缓存只用房间 / 单词序号，可能复用上一局首词节点。已在新一局清理缓存身份，并在身份中加入实际词文；随后反复重开检查真实文字和首键反馈。

- 小屏 320 × 578 游戏视口：34 / 34。系统键盘模拟收缩至 380 px 后，输入、护盾和结束按钮仍可用。
- 横屏 844 × 348 游戏视口：32 / 32。场景与输入区分列，关键控件在视口内。

最终代码的桌面完整九关：14 / 14，59.674 秒，363 次正常输入、70 个完成单词、4 次护盾、四种敌人，游戏脚本错误 0。结束回菜单后 RAF 0、声部 0、音乐调度关闭、待命中队列 0。数据摘要见 [发布回归数据](assets/storybook-qa.json)。

## 性能与释放边界

背景按尺寸和章节缓存；辉光预渲染为小图；粒子、飞字、环与提示队列有固定上限，原位回收。单词节点不再逐键销毁重建。帧间隔记录保留真实长帧，仅模拟补帧限制在 50 ms；不截短性能报告以掩盖卡顿。

地图、菜单、暂停、结束与后台状态停止 RAF 和音频调度，页面离开时销毁监听和音频上下文。三张素材约 716 KiB 压缩传输量，不等同于解码内存。计时结果只代表本机 Browser 的采样窗口，不含完整 GPU / 合成开销，不承诺所有设备 60 FPS。

最终九关测得 3,417 渲染帧，最近 600 帧的间隔中位数 16.7 ms、P95 32.8 ms，主循环提交耗时 P95 1.8 ms；全程 64 帧间隔超过 25 ms。更早一次同轮桌面回放测得 P95 18.5 ms / 提交 0.8 ms，不能只挑更好的一次宣传“全程 60 FPS”。最终峰值为粒子 102、飞行物 5、环 4、提示 4、声部 26，均在既定上限内。

## 复现与来源

```sh
node --test tests/*.test.mjs
python3 -m http.server 4175 --bind 127.0.0.1
```

打开 `tests/typebound-browser.html`，可分别运行输入与资源、动画反馈、完整九关、90 秒输入及自然失败验收。报告位于页面下方「验收数据」。所有测试结束后应留在静止菜单或结束页，测试服务器另行停止。

素材使用内置 image_gen 生成，角色与动效为原创 Canvas 2D，音频为原创 Web Audio 合成。[素材文件、完整提示词和生成方式](assets/STORYBOOK-SOURCES.md)。初版 QA 和素材报告保留，不作为本轮测量结果。

## 尚未验证的边界

手机尺寸和系统键盘是本机浏览器模拟，不代替实体 iOS / Android 的软键盘、帧率和触感。配乐已按章节和和弦关系实现并验证声部释放，但仍需要用户在实际扬声器 / 耳机上判断平衡。测试能证明行为、布局与资源约束，不能证明主观趣味性等同于商业游戏。
