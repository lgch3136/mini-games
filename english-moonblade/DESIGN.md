# 月影忍途 / MOONBLADE

独立原创单人 2.5D 横版动作闯关。参考 NES 忍者龙剑传的即时刀击、跳跃贴墙、蹬墙与消耗忍力的副武器；不复制角色、关卡、美术、音乐或 ROM 代码。

视觉：靛蓝雨夜、暖金灯火、朱红围巾。模型与硬质场景是真实 GLB / Three.js 网格，远景使用 imagegen 原创画面；刀光与火花由 Canvas2D 绘制。角色与地形共享世界投影。

三章：雨城屋脊（跳跃 / 轻敌与投射物），雾谷山道（贴墙 / 高低路线），无明寺门（组合战斗 / 两阶段首领）。每章有检查点，死亡重试不丢全局进度；无屏幕边缘刷怪。

60 Hz 固定逻辑；显示插值；短跳 / 长跳；跳跃缓冲、离地宽限；刀击起手 3 帧，连击允许预输入但不自动连按；空中刀击、下落斩、疾步闪避、手里剑。受击有短硬直与无敌时间；普通命中不震屏。

键盘 A/D 或左右移动，W / Space / K 跳跃，J 刀击，L / Shift 疾步，I 忍术，S + J 空中下落斩。触屏采用独立移动与四个动作键。P / Esc 暂停。关卡、音效和帧循环在暂停 / 隐藏 / 离开时停止。

词库使用已有 shared/vocabulary.js；探索奖励按字母推进，整词补充忍力，可关闭，不作为开门强制答题。

验收：纯逻辑输入 / 碰撞 / 忍术 / 受击 / 检查点 / 首领 / 过关测试，浏览器正式流程与手机模拟，无头浏览器不使用。画面和性能需实机核验，自动通过不等于达到原作商业完成度。
