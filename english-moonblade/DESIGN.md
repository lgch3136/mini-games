# 月影忍途 / MOONBLADE

独立原创单人 2.5D 横版动作闯关。参考 NES 忍者龙剑传的即时刀击、跳跃贴墙、蹬墙与消耗忍力的副武器；不复制角色、关卡、美术、音乐或 ROM 代码。

视觉：靛蓝雨夜、暖金灯火、朱红围巾。模型与硬质场景是真实 GLB / Three.js 网格，远景使用 imagegen 原创画面；刀光与火花由 Canvas2D 绘制。角色与地形共享世界投影。

三章：雨城屋脊（跳跃 / 轻敌与投射物），雾谷山道（贴墙 / 高低路线），无明寺门（组合战斗 / 两阶段首领）。每章有检查点，死亡重试不丢全局进度；无屏幕边缘刷怪。

60 Hz 固定逻辑；显示插值；短跳 / 长跳；跳跃缓冲、离地宽限；刀击起手 3 帧，连击允许预输入但不自动连按；空中刀击、下落斩、疾步闪避、手里剑。受击有短硬直与无敌时间；普通命中不震屏。

## 2026-09-06 · 连续操作与场景稳定性

- 输入所有权：左右同时按住时，最后一次真实按下优先，系统连发不改变优先级；释放新方向后恢复仍按住的旧方向。键盘别名与各个手指互不抢释放。短于一个逻辑帧的方向 + 招式输入也保留正确朝向。
- 地面起跑 3 个逻辑帧到 7.5 单位/秒；松开 2 帧停下；反向在第一个逻辑帧产生反向位移。这里是模拟响应，不是输入到屏幕的硬件延迟测量。
- 方向先于出刀、疾步与手里剑解析。反向可结束原方向的刀击/疾步，不再边后退边朝错误方向攻击；轻刀保持跑速。疾步末段允许 140 ms 刀击预输入。
- 显示动画与物理分离：70 ms 的真实三维转体；跑、空中、贴墙、疾步、受击分层；先混合控制点，再解固定长度 IK。下落接近地面时提前伸腿，脚接地不等待上半身动画结束。步幅与位移对应，不能靠播放频率制造滑步。
- 同一 Blender 人物的 18 个独立部件合成一个刚性权重 SkinnedMesh；所有顶点、索引、顶点色保留，每个部件仍有独立骨骼，几何在角色间共享，骨骼不共享。逐顶点对照原模型在左右朝向和多组关节变换后的坐标。场景重建时释放骨骼纹理，离页释放共享几何与材质。
- 双向前视的临界阻尼镜头；普通跳起/落地不动竖向镜头、不缩放、不震屏。镜头只记录碰撞确认的地面高度，不能把显示插值中的半空坐标当成新地面。高落差着地反馈最多 0.032 世界单位，尊重减少动态效果设置。
- 靛蓝月光勾边、固定位置的暖灯光池、落在实际平台上的接触影；复用 1 个临近灯笼点光源 + 1 个命中点光源。刀光取模型的真实刀刃端点，仅在挥刀有效期拖尾，和角色的转身使用同一个投影。大面积石墙使用轻量漫反射，角色、刀刃和屋瓦保留 PBR。无全屏 Bloom / 运动模糊 / 景深通道。
- 墙体、檐口与铺面分层构造；可走表面和碰撞高度一致，但不能让三个顶面共面。用连续跳跃的地形像素稳定性测试回归深度闪烁。

视觉参考：[Alex Finn 的 NULL DISTRICT 演示](https://x.com/AlexFinn/status/2096065384290128372)。参考点是角色与环境受光、地面锚定和镜头连续性；那是俯视射击演示，本作仍是横版忍者平台动作。没有取得该演示的源代码，也没有从压缩视频推断或宣称复现其帧率、输入延迟。

键盘 A/D 或左右移动，W / Space / K 跳跃，J 刀击，L / Shift 疾步，I 忍术，S + J 空中下落斩。触屏采用独立移动与四个动作键。P / Esc 暂停。关卡、音效和帧循环在暂停 / 隐藏 / 离开时停止。

词库使用已有 shared/vocabulary.js；探索奖励按字母推进，整词补充忍力，可关闭，不作为开门强制答题。

验收：纯逻辑输入 / 碰撞 / 忍术 / 受击 / 检查点 / 首领 / 过关测试，浏览器正式流程与手机模拟，无头浏览器不使用。画面和性能需实机核验，自动通过不等于达到原作商业完成度。
