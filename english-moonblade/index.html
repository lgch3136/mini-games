THE WAY OF MOONBLADE

动起来，再出刀。

移动 / 跳跃
A D 或 ← → 移动；空格、K 或 W 跳跃。长按跳得更高，轻点短跳。
贴墙 / 蹬墙
空中靠住墙，缓缓下滑；再按跳跃蹬离墙面。迅速转回墙面可继续攀升。
三段刀击
J 出刀，连续点按接三段。空中也能出刀；↓ + J 是下落斩。
疾步 / 忍术
L 或 Shift 短距闪避，有冷却；I 投手里剑，每次消耗一格忍力。击倒敌人、探索高处可补充。
检查点与暂停
经过朱色小门会保存检查点并少量回血。P / Esc 暂停；离开窗口自动暂停。触屏建议横屏，左右手独立操作。

原创三章动作游戏，参考经典忍者平台动作的规则，不是原版 ROM 移植。
