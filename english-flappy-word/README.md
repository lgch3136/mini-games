# 飞鸟背单词 · FLAPPY WORDS

一款把经典 Flappy Bird 与英语学习结合起来的网页小游戏：**扇动翅膀，穿越管道，拼出单词，攻克语法**。

🔗 在线游玩：https://lgch3136.github.io/mini-games/english-flappy-word/

## 运行方式

直接用浏览器打开 `index.html` 即可（无需服务器）：

- macOS: `open index.html`
- 或双击 `index.html`

## 玩法

两种模式（主菜单可选）：

1. **🔤 拼单词**：顶部显示中文释义和字母进度（如 `a _ _ l e`），途中飘来的字母气泡**都是当前需要的下一个字母**，碰到即收集，按顺序拼出完整单词——没有干扰项、没有惩罚，专注穿越管道即可。
2. **🚪 闯关选择**：顶部显示题目（语法填空 / 中文选英文），管道墙上开有上下两个门洞，各挂一个选项——穿过**正确答案**的门洞得分，穿错扣 1 条命。

通用规则：

- 撞到管道、墙壁或地面都会扣命，共 3 条命 ❤️；扣命后有短暂无敌闪烁。
- 💡 H 键提示（扣 15 分）：拼单词显示完整单词；闯关模式高亮正确门洞。
- 每穿过一根管道 +1 分；连击（连续拼词/答对）有额外加分。
- 每完成 5 个单词/题目升 1 关：飞行速度加快并回复 1 条命（最多 3 条）。
- 最高分按模式+难度保存在浏览器 localStorage。

## 文件结构

- `index.html` — 页面结构
- `style.css` — 界面样式
- `data.js` — 题库（词汇 + 语法，三档难度，与合集其他游戏共用结构，可自行增删）
- `game.js` — 游戏引擎（物理、碰撞、门洞、气泡、音效、关卡逻辑、自检）
- `assets/` — 素材：`logo.png` 菜单图、`bird.png` 小鸟、`pipe.png` 管道、`bg.png` 背景（均由 Codex 图像生成并做透明处理；缺失时游戏会回退到程序绘制）

## 自定义题库

直接编辑 `data.js`：

- 词汇格式：`{ en: 'apple', zh: '苹果' }`（拼单词模式使用 3~9 个字母的单词）
- 语法格式：`{ prompt: 'I ___ a student.', options: ['am','is','are','be'], answer: 'am' }`（闯关模式会从中随机抽取 2 个选项挂在门洞上）

## 内置自检

URL 加参数可触发无头测试（供 CI / 无头浏览器使用）：

- `?selftest` — 题库格式校验 + 拼词/答题/碰撞/升级链路，通过后页面标题为 `SELFTEST-OK`
- `?fuzz` — 15000 帧随机+智能飞行的模糊测试，标题为 `FUZZ-OK ...`
- `?probe` — 渲染像素探针，标题为 `PROBE ...`
