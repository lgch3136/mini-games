固定画面阴影对照 QA

这是自愿使用的诊断工具，不是性能升级。尚未完成真实 GPU、画面与手机触控验收，不能据此宣称正常游玩帧率改善。人物、贴图、光照和正常画质沿用 R25。

使用独立诊断存档，不读取或覆盖 R25 旅程。进入后仍需手动点击“固定画面并开始”，不会自动运行。可先步行到林地或营地、调整镜头，再开始。

进入标准档阴影诊断进入低档阴影诊断
  1. 站定后点击左上方阴影面板的“固定画面并开始”
  2. 等待阴影开启 → 关闭 → 再开启，期间世界和镜头固定
  3. 结束后读取结果；“复制诊断结果”只复制文本，不自动发送。复制不可用时可手动选择下方 JSON
  4. 随时按 Esc 或“取消并恢复”；离开页面、切换窗口或改变尺寸会中止

GPU 计时不可用或对照无效时会明确标注，不用回调 fps 代替 GPU 结论。独立存档需要正常探索后才能获得相应坐骑；不会自动传送或解锁。
