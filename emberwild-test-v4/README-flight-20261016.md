本版基于大厅原来的 R16 完整游戏，更新狮鹫飞行操控、倾斜与起降衔接。日期为 2026-10-16，版本标识为 `r16-flight-20261016-r1`。保留同一人物、任务、地面骑乘、战斗、世界资产和存档格式。不是全部 QA 分支更新。

## 操作

- 完成守灯人委托、交还两枚余烬后解锁曙翼狮鹫。打开坐骑菜单，在空地且远离敌人处召唤；骑乘后按空格起飞
- 稳定飞行后，按住鼠标右键 + W，或同时按住左右键，沿当前画面的视线飞行。抬头上升，低头下降；S 反向，A/D 横向移动
- 右键单独转向不会开始前进。松开右键或用左键观察时，仍按着的移动沿最后的方向继续；松开移动键会立即停止由视线产生的升降。重新单按 W 是水平前进
- 空格 / Shift 分别手动上升 / 下降，优先于视线的升降分量；原有手动按键的缓动保持不变
- 通过界面上的「降落」或显示的对应按键着陆；先降落再下骑。飞行中可抬头/低头观察至约 ±85°，地形与镜头避让仍会限制实际视角
- 触屏仍使用水平摇杆与明确的上升/下降按钮；未增加手柄支持

## 验证与边界

最终合并模块通过离线操控、物理、生命周期、真实坐骑模型与骑手接触测试；标准/低模两档的抽样姿态与碰撞包围检查通过。动画包含飞行倾斜、翼尾姿态、起飞与落地衔接。

这些结果来自 CPU / 源码测试及离线画面检查。完整浏览器场景、连续渲染动画、真实鼠标/触屏设备、GPU 与帧率尚未验收；不宣称性能改善。原有地形限高、碰撞和任务解锁规则保留。
