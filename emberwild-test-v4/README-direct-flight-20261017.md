基于 R16 完整游戏和 10/16 飞行修复版，沿用人物、任务、战斗、世界和同一存档。R25 QA 与独立人物预览没有合并到这个入口。

## 操作与变化

- 骑上已解锁的狮鹫后按空格直接起飞，无需额外飞行设置。先收翼离地，确认安全后展开双翼；真实上方障碍仍会阻挡起飞并让坐骑落回地面
- 右键 + W，或左右键同时按住，沿画面视线飞行；抬头上升、低头下降。空格手动上升，Shift 手动下降
- 通过「降落」着陆：先收翼，再沿安全路径下降。普通可行走坡面不再因为地面的全展翼预检而被误拒绝
- 地面步行与跑步保留腿部步态，增加身体重心和折翼随动；双翼改为肩关节与翼端共同折向侧后方，为骑手腿部留出空间
- 落地后的再次起飞会等待脚站稳，无需反复按键。展翼途中按降落，会先完成避开骑手的展翼动作，再自动收翼着陆。实际障碍、陡坡、世界边界和飞行限高仍有效
- 原有左拖观察、右拖转向、滚轮缩放和背包输入保持；徒步空格仍是跳跃。触屏保留摇杆与上升/下降按钮

## 验证与限制

通过源码、控制器、生命周期、真实坐骑和骑手的 CPU 姿态/碰撞检查。测试覆盖两档坐骑模型、坡面、折翼/展翼过渡、窄处着陆、障碍取消、重复起降和地面步行/跑步。离线画面用于对比姿态，并非游戏浏览器截图。

完整浏览器 WebGL、连续交互动画、真实鼠标/触屏设备和帧率尚未验收；不宣称帧率提升。地形碰撞使用有界采样，不能据此宣称任意狭窄突刺或所有可能姿态都已检查。模型原有肩部连接重叠没有作为独立建模问题重做；低档模型原生拍翼的一个抽样末端仍有既存的翼面/腿部接触，本次没有宣称整个模型完全无穿插。
