# 余烬旷野 · r10 运行检查点

原创第三人称奇幻冒险。营地接下守灯人的委托，穿过山谷，击败古塔与月池守卫，寻回两枚余烬，回营领取奖励，再用星币与残片升级装备和补给。

r10 更新实际角色、林缘树冠和中层植被、手工营地结构、石组及地表。玩法、存档、输入、技能、背包和原创配乐沿用已验证系统。每次仅加载所选质量档的 characters / flora / camp 三个 r10 GLB，三张地表颜色图；标准档另用保留的土壤法线和粗糙度图。图标由一个 WebP 图集提供，音乐在本地实时合成，没有音频下载。

## 启动

实际入口：app/index.html。在包含 app 的解压目录运行：

    python3 -m http.server 4173 --directory app

在已启用 WebGL2 的浏览器打开 http://localhost:4173/。不需要 npm、账号、API Key 或外部 CDN。直接双击 file:// 不作为支持的启动方式。可加 ?quality=standard 或 ?quality=low；粗指针触屏默认低档。

## 操作与存档

- WASD 按镜头方向移动；左键拖动观察，右键拖动转向，双键按住前进，滚轮缩放
- 右键按住时 A/D 侧移；左拖观察和松开鼠标后保持已经开始的移动方向，停止所有移动后再按 WASD 才采用新镜头方向
- F 挥剑、Shift 闪避、空格跳跃、E 互动；数字 1–9 使用技能或道具槽，Q/R 为默认附加快捷键
- Tab 打开实时图形背包，不暂停世界、敌人、冷却和音乐；Esc 先关背包，再按一次暂停
- 背包显示真实数量、装备与补给，可使用药剂和调整技能栏；营地交易遵循现有星币和残片规则
- 设置界面、后台和暂停冻结模拟；返回后重新按移动键。触屏有摇杆和动作按钮

经验、任务、背包、位置、探索和冷却自动保存到当前浏览器本地存储。死亡重试保留进展，不补发药剂或重复奖励。旧版存档可迁移；损坏或未来版本存档保留原数据。清除站点数据或换浏览器不会保留旅程。固定种子地图可延伸；存档、探索记录和活动范围有上限。

原创配乐《蕨间灯火》在首次真实交互后启动，有探索和战斗配器，可独立调音量或静音。暂停、后台和静音不会堆叠音符。

这是完整运行候选。实际游戏模块、Three.js、GLB、角色关节、RPG、输入、背包、动作和音乐调度已通过 CPU 适配回归。CPU 场景图使用生产几何、镜头与光源，但近似光照、材质和透明度。它们不是浏览器截图，不能证明真实 GPU 帧率、内存分配、原生鼠标或触控手感、手机布局或扬声器听感。资源数量不等于实测 FPS；生成目标图只是美术参考。未声称已达到目标插画或完成 Premium 视觉与性能验收。

本运行包只含实际可达模块、厂商依赖、模型、贴图、图标及许可。配套 r10 可编辑源包含 Blender 文件、直接重建输入、素材来源、配乐源、工具和紧凑验证证据；不需要较早源压缩包。Three.js 许可见 app/vendor/LICENSE；资产说明见 app/ASSET-NOTICES.txt。精确运行哈希在配套源包 docs/runtime-manifest.json。
