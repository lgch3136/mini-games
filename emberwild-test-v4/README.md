# 余烬旷野 · r11 第一批运行检查点

第三人称奇幻冒险：在营地与守灯人交谈，明确接下委托，穿过山谷、击败古塔与月池守卫、寻回两枚余烬，再回营选择完成任务领取奖励。装备和补给沿用现有星币与残片规则。

本批更新英雄造型与材质、双踝和屈膝跳跃表现、落地效果、近景镜头，以及任务对话、背包入口、角色和目标头像框、点选与键盘切换目标。英雄头颈以 CC0 MakeHuman 图形基网格为解剖拓扑基础，进行了项目原创塑形、造型和贴图；其余服装、装备、参考图和材料设计是项目素材。r10 林地、营地、地表与三类 NPC 保留；v2 存档、伤害和运动物理、1–9 技能栏、原创音乐继续使用已有系统。独立准备的后续 progression / wildlife 模块与野怪模型不在本运行包，也不属于本批已实现功能。

## 启动

实际入口：app/index.html。在运行包根目录执行：

    python3 -m http.server 4173 --directory app

在支持 WebGL2 的浏览器打开 http://localhost:4173/。不需要 npm、账号、API Key 或外部 CDN。直接双击 file:// 不是支持的启动方式。可用 ?quality=standard 或 ?quality=low；粗指针触屏默认低档。

一次只加载所选档位的 characters-r11、flora-r10、camp-r10 三个 GLB，以及该档的三张地表颜色图。标准档另用保留的土壤法线、粗糙度；UI 使用原有单张 WebP 图标集和对应档位的角色头像。标准头像 256×256，低档 128×128，均由实际角色几何渲染。音乐本地实时合成，没有音频下载。

## 操作

- WASD 按镜头方向移动；左键拖动观察，右键按下立即按镜头方向对齐角色、拖动转向，双键按住前进，滚轮缩放
- 按住右键时 A/D 侧移；左拖观察及松开鼠标后保持已开始的移动方向，停止移动后重新按 WASD 才采用新镜头方向
- F 挥剑、Shift 闪避、空格跳跃、E 互动；1–9 使用技能或道具槽，Q/R 是默认附加快捷键
- B 打开实时图形背包；自定义按键占用 B 时，界面显示未占用的备用键
- Tab / Shift+Tab 切换可见敌人；点击或轻触角色选择目标，选择本身不发动攻击，左拖与右拖仍保留镜头操作
- 背包显示真实数量、装备、补给，支持使用药剂及调整技能栏。背包和任务对话不暂停世界、敌人、冷却和音乐
- 首次和再次打开守灯人对话都不会自动接取任务或领奖；必须选择接取或完成按钮。离开守灯人 3.2 米后结束交谈
- Esc 先关闭当前界面，再按一次暂停；设置、后台和暂停冻结模拟。恢复后重新按移动键。触屏提供摇杆及动作按钮

## 存档与音乐

经验、任务、背包、位置、探索和冷却自动保存在当前浏览器本地存储。死亡重试保留进展，不补发药剂或重复奖励。旧存档可迁移；损坏或未来版本的存档保留原始数据。清除站点数据或更换浏览器不会保留旅程。固定种子地图可延伸；存档、探索记录和活动范围均有上限。

原创配乐《蕨间灯火》在首次真实交互后启动，有探索和战斗配器，可独立调音量或静音。暂停、后台和静音不会堆叠音符。
