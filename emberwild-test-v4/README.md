# 余烬旷野 · 本地独立低档英雄候选

状态：未晋级的待验候选，不作为所有档位已通过流畅性验收的默认升级。低档英雄已有独立保形LOD；主v2与v3保留回退。

唯一运行入口：`app/index.html`。本包只含 `app/`，可编辑源扩展只含 `authoring/`；需要编辑时将两包放在同一项目目录。运行不依赖源包，不用 npm，也不请求外部 CDN。旧主包 v2 与独立小样均保留，没有发布网站。

在包含 app 的项目目录启动普通静态服务，例如：

`python3 -m http.server 4173 --bind 127.0.0.1 --directory app`

服务入口为 `http://127.0.0.1:4173/`。应通过 HTTP 打开，不直接用 file://。这是运行方式说明；本轮未把 HTTP 文件完整性检查当作真实浏览器 WebGL 验收。

## 已整合

- 行走/攻击/闪避呈现与常态不透明、必要薄面单次绘制优化
- 连续受光披风、薄折边与接缝结构
- 四类真实生产纹理、营火暖光、有限树隙光束与短动作光轨
- 一处路边石的偏心折脊与局部斜裂口，位置、原碰撞与镜头避障代理保留

本轮新增跳跃和左手动作键；没有新增地图、敌人或重攻击，未把单石扩到全场。

## 操作

WASD 移动，拖动场景转镜头，F 挥剑，Shift 闪避（左右 Shift 均可），空格跳跃，E 互动，Esc 暂停。界面保留触屏摇杆、挥剑与闪避按钮，并提供独立跳跃按钮，但手机实机未验证。

跳跃由竖直速度与重力驱动，落地后才能再次起跳；按住空格不会连续跳跃。空中仍可移动、挥剑与闪避，原攻击间隔、闪避冷却和闪避无敌时间不变；跳跃本身不提供无敌，也不重置攻击。树木、岩石等原水平碰撞在空中同样生效。暂停、失焦或切到后台会冻结跳跃；恢复时需重新按移动键，死亡重试会清除竖直速度并回到营地。向营地守灯人接取任务，击败相应守卫后找回两枚余烬，再回营交还。死亡可重试并保留本次任务和宝箱进度；刷新不保存旅程。

可在 URL 加 `?quality=low` 或 `?quality=standard`；粗指针触屏默认低档，切档需要重新载入。世界库不含英雄。标准只载标准英雄、当前标准石LOD和12张贴图；低档只载独立低模英雄、低石LOD和4张256色图，不同时加载两档英雄或石头。

## 预算与未通过项

- 标准英雄保持v3的46个运行mesh、20176三角、16412渲染顶点；低档为35/12664/10206。低档相对v3减少37.2%三角、37.8%渲染顶点、23.9%颜色及太阳阴影mesh提交（46+46→35+35），这是资源计数，不能称GPU流畅性通过
- 原内部优化目标7500三角/28提交未达。为保原轮廓和PBR参数，本轮停止在上述保形版本；没有为凑数删主要结构
- 16方位×284实际动作帧×两距离，共9088隔离英雄视图，完整轮廓误差正常≤1px、近景≤2px；88脚底点、12动作节点、剑尖与原参考一致。属于CPU几何验证，近景脚底采用明确的overscan诊断，不是游戏截图。玩法37项回归通过
- 标准英雄GLB 675332字节，低档548048字节（−18.8%）；合批增加顶点色属性，以保留原线性色彩。纹理仍沿用既有低档资源，没有因英雄LOD增加贴图
- 解析后唯一几何typed-array存储631352→507100字节（−19.68%）；按每mesh属性逻辑求和646016→516904字节。低模新增122472字节顶点色，已计入，不能把37.8%顶点下降当内存下降
- 标准贴图RGBA8含mip估计约12 MiB，低档约1.33 MiB；点灯可见上限4/2，只有太阳投影。有限光效最多6/3个额外透明绘制节点。这些不是FPS或显存实测
- WebGL实际外观、GPU帧率、手机触控、音效与持续操作手感仍未验收。交付预览是生产资源的CPU离线图，不含最终UI，也不能证明动态透明排序
- 近景CPU隔离图中低档兜帽下缘有少量额外亮点，尚不能区分离线采样噪声与实际着色差异；不承诺像素级材质一致。低档仍采用既有256色图且不载法线/粗糙度图
- 披风针脚仍偏块、纵缝末端有暗楔；皮革缺部位磨损，苔藓可读性弱；NPC、部分岩石及全场艺术统一性仍不够精细
- 目标5–10分钟片段没有真人计时证据，熟练直达流程可能明显更短。星币也没有消费用途
