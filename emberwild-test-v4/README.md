# 余烬旷野 · r14 地面骑乘与飞行

r14 加入原创苔冠鹿与曙翼狮鹫，支持召唤、上鞍、地面骑行、起飞、升降、安全降落及下骑。保留 r13 的实时背包施法和目标锁定；角色、场景与既有成长和战斗资源沿用已发布版本。坐骑几何和动作按原制作记录重建，使用本轮新生成的原创材质；不声称这些模型字节等同于此前未发布的文件。

第三人称奇幻冒险：在营地与守灯人交谈，明确接下委托，穿过山谷、击败古塔与月池守卫、寻回两枚余烬，再回营选择完成任务领取奖励。装备和补给沿用现有星币与残片规则。

英雄在 r11 骨架基础上调整了脸部、眼睑、成束发型、短颈、领口、小护肩与分叉衣摆；保留双踝和屈膝跳跃、落地效果、近景镜头，以及任务对话、背包入口、角色和目标头像框、点选与键盘切换目标。英雄头颈以 CC0 MakeHuman 图形基网格为解剖拓扑基础，进行了项目原创塑形、造型和贴图；其余服装、装备、参考图和材料设计是项目素材。r10 林地、营地、地表与三类 NPC 保留；运动物理、1–9 技能栏、原创音乐继续使用已有系统。r12 接入三种野外战斗行为、真实地面战利品、材料配方、有限天赋选择和三种远程法术；真实升级触发光环、短音和等级/属性提示。野猪与飞蛾是两套原创模型，石背冲角兽共用野猪结构并调整体型和材质。具体测试覆盖和未验证项记录在配套报告中；模型仍有简化，未宣称达到目标参考图的表现力。

## 启动

实际入口：app/index.html。在运行包根目录执行：

    python3 -m http.server 4173 --directory app

在支持 WebGL2 的浏览器打开 http://localhost:4173/。不需要 npm、账号、API Key 或外部 CDN。直接双击 file:// 不是支持的启动方式。可用 ?quality=standard 或 ?quality=low；粗指针触屏默认低档。

一次只加载所选档位的 characters-r12、flora-r10、camp-r10、wildlife-r11 模型库、loot-r12 掉落袋及该档的两种坐骑，以及该档的三张地表颜色图。标准档另用保留的土壤法线、粗糙度；UI 使用原有单张 WebP 图标集、新材料/法术图标集和对应档位的角色/野怪头像。标准头像 256×256，低档 128×128，均由实际角色几何渲染。音乐本地实时合成，没有音频下载。

## 操作

- WASD 按镜头方向移动；左键拖动观察，右键拖动转向，双键按住前进，滚轮缩放
- 按住右键时 A/D 侧移；左拖观察及松开鼠标后保持已开始的移动方向，停止移动后重新按 WASD 才采用新镜头方向
- F 挥剑、Shift 闪避、空格跳跃、E 互动；1–9 使用技能或道具槽，Q/R 是默认附加快捷键
- 新旅程的 4、5、6 槽依次是焰矢、霜棘、星坠；旧旅程保留原技能编排，从“编排技能”选择法术放进空槽
- B 打开实时图形背包；自定义按键占用 B 时，界面显示未占用的备用键
- Tab / Shift+Tab 切换可见敌人；点击或轻触角色选择目标，选择本身不发动攻击，左拖与右拖仍保留镜头操作
- 目标框提供“锁定目标 / 解除锁定”，快捷键按当前空闲按键自动选择并在按钮上显示；锁定后手动切换目标会明确转移锁定，受击自动选择不能覆盖锁定
- 背包显示真实数量、装备、补给，支持使用药剂及调整技能栏。背包和任务对话不暂停世界、敌人、冷却和音乐；普通背包按钮焦点下仍可按数字或辅助技能键施法，也可点击技能栏，点击物品本身不会触发世界攻击
- 首次和再次打开守灯人对话都不会自动接取任务或领奖；必须选择接取或完成按钮。离开守灯人 3.2 米后结束交谈
- 击败敌人获得经验，靠近地上的战利品袋按 E 或触屏互动拾取；满额物品仍留在原处，背包只计入实际拾取的数量
- “研习”可查看三系天赋和材料配方；学习、重置及制作均须回到营地，打开界面不暂停世界
- Esc 先关闭当前界面，再按一次暂停；设置、后台和暂停冻结模拟。恢复后重新按移动键。触屏提供摇杆及动作按钮

## 坐骑与飞行

- 顶部“坐骑”或营地入口“坐骑驿站”打开选择。默认 G；被旧存档绑定占用时，界面显示实际空闲备用键
- 苔冠鹿从开始即可召唤。交还两枚余烬并点击完成守灯人委托后解锁曙翼狮鹫，读取已有任务进度
- 召唤需要角色站稳、平坦开阔空间，并离活着的敌人 8 米。上鞍、收步和下骑需等当前过渡完成
- WASD / 摇杆骑行；先朝输入方向踏步转身，再沿通过障碍检查的朝向前进。Shift 缓步，最高骑行速度 6.1 米/秒
- 狮鹫空格起飞；持续按住空格上升，Shift 下降，离地上限 18 米。顶部“降落”或原挥剑键（默认 F）检查落脚区域并连续降落；陡坡或障碍处需先移到开阔平地
- 安全着陆、收翼后，同一按钮变成“下骑”。两侧和后方都没有安全落脚通道时保持骑乘，不能从半空下骑
- 触屏复用原动作按钮：起飞/按住上升、按住下降、降落/下骑。骑鹿只显示下骑；窄屏骑乘提示暂时占用任务文字位置
- 骑乘时战斗、技能和互动要求先下骑，飞行时先安全降落。拒绝操作不消耗技能冷却。地面骑手仍受敌人伤害，高空不会被远低于自身的地面近战击中
- 背包不暂停世界。暂停、后台、失焦及界面切换释放持续输入；恢复后重新按键。坐骑状态不写入存档，重载回到已验证的安全地面位置，保留原进度、物品与冷却

## 远程法术

选中敌人后对准目标施法；未选敌人且未锁定时沿角色朝向发射。明确锁定会固定法术的目标意图；锁定目标死亡、离场或超过 40 米后保留可见失效原因，并阻止向别的目标或空处偷偷发射，直到主动重选或解除锁定。每种法术自身较短的射程和视线检查仍然有效。一次读条开始后保留当次目标和朝向。焰矢是快速火焰弹，霜棘命中后短暂减慢目标移动和攻击，星坠在落点造成有限范围伤害。技能说明列出射程、施法时间与冷却。地形、树干和岩石会阻挡，重盾正面仍能格挡；飞行中的弹体不会自动追踪已经移开的目标。

移动、跳跃、闪避、真正的文字输入/改键事务、设置暂停或失焦会取消尚未发射的施法，不消耗冷却；实际发射后进入冷却与收势。普通背包的打开、物品选择和关闭不再取消读条，已发射弹体也继续随世界运行。背包按钮的 Enter/Space 和方向键仍用于原生界面操作。法术有可见施法条、手部姿态、飞行核心/拖尾和命中反馈，两档使用固定数量的表现对象，低档容量更低。施法时间、收势、射程和各自冷却约束连续使用。

## 成长与营地

等级沿用原有经验系统，最高 10 级；2、4、6、8、10 级各获得一个天赋点。烬刃研习提升剑伤，长明守护延长护身并缩短冷却，林间药理提升药剂治疗并缩短冷却，各两阶。营地花费 20 星币重置已投入点数，不重置生命、技能冷却或已生效的护身时间。

荆枝潜行者会绕行扑击，月沼吐辉者锁定地面范围，石背冲角兽预告冲撞路径；看见预告后可以移开或闪避。三种材料来自实际战利品：两份荆枝花与一份月辉树脂可调配两瓶药剂，两份石角片可换三份残片。旧的营地装备升级继续使用星币与残片。任务守卫仍负责两枚余烬的主线条件。

## 存档与音乐

经验、任务、背包、位置、探索和冷却自动保存在当前浏览器本地存储。死亡重试保留进展，不补发药剂或重复奖励。r12 使用独立的 v3 存储键，首次读取旧旅程后迁移，不改写旧 v2 存储，避免已打开的旧版本标签页覆盖天赋和战利品。损坏、未知或未来版本的存档保留原始数据。检测到另一个 r12 标签页更新旅程时，本次会话停止保存并提示重新加载；这属于写入前冲突检测，不是多标签页并发事务锁。清除站点数据或更换浏览器不会保留旅程。固定种子地图可延伸；存档、探索记录和活动范围均有上限。

原创配乐《蕨间灯火》在首次真实交互后启动，有探索和战斗配器，可独立调音量或静音。暂停、后台和静音不会堆叠音符。
