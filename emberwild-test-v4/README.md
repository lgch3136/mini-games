# 余烬旷野 · 第一章公开测试候选

原创第三人称奇幻冒险。营地接下守灯人的委托，穿过山谷，击败古塔与月池守卫，寻回两枚余烬，回营领取奖励，再用星币与残片升级装备和补给。地图以固定种子延伸；当前存档、探索记录和活动范围有上限，不是 MMO。

## 本次试玩修正

跳跃改为实际关节驱动的压缩、蹬伸、收腿、下落与落地缓冲，仍沿用原重力和起跳速度。烬刃出现贴合剑刃的蓄光、挥动弧线与真实命中反馈；护身显示与剩余时间同步的青色轮廓；成功治疗才显示绿色上升光纹。特效复用四个固定绘制节点，不新增贴图、灯或阴影，低档保留同样可辨的大小与时序。

地表采用新的原创土路图像经 Blender 烘焙的颜色/法线/粗糙度图；近景一棵树换成曲线树干与分组叶片。土路贴图尺寸与地形不变，新树保留原移动碰撞，镜头避障改用新树实际网格。其它树木、NPC 和远景仍有明显粗糙之处，当前画面没有达到生成目标图的完成度。

## 运行与操作

唯一入口为 `app/index.html`。用支持并启用 WebGL2 的浏览器通过 HTTP 打开。本包自带运行依赖，不需要 npm、账号或外部 CDN。可在包含 app 的目录运行 `python3 -m http.server 4173 --directory app`，再访问 `http://localhost:4173/`。

- WASD 按镜头方向移动（角色朝移动方向；按住右键时 A/D 侧移并保持朝向），左键拖动独立观察，右键拖动同时转动镜头与角色，双键按住前进，滚轮缩放（3–13 米），F 挥剑，Shift 闪避，空格跳跃，E 互动，Esc 暂停
- 数字键 1–9（包括小键盘）对应九个技能/道具槽；空槽明确留空。默认 1 烬刃、2 灯火护身、3 暖露药剂，Q/R 是前两槽的附加快捷键
- 左拖观察时保持原移动方向，松开鼠标而移动键仍按住也不会突然转向；停止所有移动后，下次 WASD 使用当前镜头方向。右键可立即重新对齐角色与镜头。
- Tab 打开背包与技能栏侧面板（不暂停），世界、敌人、冷却和音乐继续运行；点击场景可继续移动与施法。Esc 先关闭面板，再按一次明确暂停。设置仍会暂停，若从原有暂停界面打开，关闭设置仍保持暂停。
- 背包可点击、触屏或拖动编排槽位并修改附加快捷键。基础挥剑/互动键发生冲突时会明确确认交换，提示随配置更新
- 触屏有摇杆、挥剑、闪避、跳跃和技能槽；手机实机体验仍待验证
- 跳跃需落地后重新按键。跳跃不提供无敌，不重置攻击或闪避冷却；空中保持原水平碰撞

## 成长、地图与音乐

小地图朝北，显示朝向、已探索地区、地标和任务方向；敌人提示受距离、探索与遮挡约束，最多每秒更新八次。

击败守卫、开箱和交还余烬获得经验、星币与残片；营地可升级剑、升级补给或购买药剂。已领取的击杀、宝箱和任务奖励不会通过刷新重复领取。烬刃冷却 6 秒；护身持续 4 秒、冷却 14 秒；药剂默认恢复 45 生命、冷却 8 秒。重复放入多个槽仍共用同一冷却和数量。

旅程与设置自动保存在当前浏览器的本地存储，包含任务、背包、经验、位置、探索与冷却。死亡重试回到营地并保留进展，不补发已消耗药剂。暂停或切到后台会冻结模拟；恢复后需重新按移动键。更高版本或损坏存档会保留原始数据，存储被禁用或容量不足时会提示；跨浏览器或清除网站数据不会保留旅程。版本 1 存档可迁移到版本 2。

原创配乐《蕨间灯火》含营地/探索主题与战斗配器变化，与音效共享音频上下文；首次真实交互后才启动，可独立调音量或静音。暂停、后台和静音不会继续堆叠音符。

## 画质与制作范围

URL 可选 `?quality=low` 或 `?quality=standard`；粗指针触屏默认低档。每次只请求一档英雄、营地、前景树和路边石资产，不同时加载两档。只有太阳产生阴影，低档降低分辨率、贴图、局部灯与透明光效上限。

新英雄与营地先制作原创图像参考，再用 Blender 建立实际拓扑、UV、材质与细节。英雄披肩用三个已有动作节点局部蒙皮，其余关节和脚底保持原逻辑。营地加入木构接合、薄篷布、旗帜、床铺与储物结构，保持原位置、通路和碰撞。运行包不含原图、Blender 工程或离线渲染工具；可编辑内容在独立源更新包，完整旧源历史另行保留。

## 已验证与限制

生产代码的战斗、真实跳跃、存档迁移/重复奖励、九槽编排/按键、暂停/死亡恢复、音乐调度及资源选择均有自动化验证。资源加载与几何检查使用实际 Three.js/GLB，DOM、图片解码和渲染器在测试中采用适配层。CPU 制作预览不等于浏览器游戏画面。

当前环境 WebGL2 被禁用，因此实际 WebGL 外观、GPU 帧率、手机触控、浏览器布局/拖动、扬声器听感与连续操作手感尚未验收。5–10 分钟首段是设计目标，没有真人计时证据。英雄披肩仍偏硬、发型和 NPC 尚不够自然，场景艺术统一性也仍需打磨。几何/绘制下降不代表已经证明 FPS 提升；新增独立图集会增加纹理预算。
