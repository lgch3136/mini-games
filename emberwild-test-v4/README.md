# 余烬旷野 · r9 材质与场景候选

原创第三人称奇幻冒险。营地接下守灯人的委托，穿过山谷，击败古塔与月池守卫，寻回两枚余烬，回营领取奖励，再用星币与残片升级装备和补给。地图按固定种子延伸；存档、探索记录和活动范围有上限。

r9 细化角色衣褶、手部与头发，调整草地与岩石的形体和材质、河岸覆盖，以及营火形体、局部动态和生产光照。r8 的玩法、存档、左手键鼠输入、1–9 技能栏、实时图形背包、动作和原创配乐保留。角色、自然 GLB 仍沿用 r8 文件名；建筑改用 architecture-*-r9.glb，以 BUILD.json 哈希识别具体内容。

## 启动

实际入口是 app/index.html。使用支持并启用 WebGL2 的浏览器，经 HTTP 打开。在解压后包含 app 的目录运行：

    python3 -m http.server 4173 --directory app

然后访问 http://localhost:4173/ 。不需要 npm、账号、API Key 或外部 CDN；Three.js 及加载器均在包内。直接双击 file:// 文件不作为支持的启动方式。

URL 可用 ?quality=low 或 ?quality=standard；粗指针触屏默认低档。每次只加载所选档的角色、自然、建筑三套 GLB、三张地表颜色贴图；标准档另加载保留的土壤法线和粗糙度贴图。图标由共享 WebP 图集提供。两档均已收在包内。

## 操作

- WASD 按镜头方向移动；左键拖动观察，右键拖动转向，双键按住前进，滚轮缩放
- 右键按住时 A/D 侧移；左拖观察和松开鼠标后继续保持已开始的移动方向，停止所有移动后再按 WASD 才采用新镜头方向
- F 挥剑、Shift 闪避、空格跳跃、E 互动；数字 1–9 对应技能或道具槽，Q/R 为默认附加快捷键
- Tab 打开实时图形背包，不暂停世界、敌人、冷却和音乐；Esc 先关背包，再按一次明确暂停
- 背包显示真实物品数量、装备与补给，可直接使用药剂、调整技能栏；营地交易遵循现有星币和残片规则
- 设置界面暂停；后台或暂停冻结模拟，返回后重新按移动键
- 触屏提供摇杆与动作按钮；手机实际布局、触控和性能尚待验收

经验、任务、背包、位置、探索和冷却自动保存到当前浏览器本地存储。死亡重试保留进展，不补发已消耗药剂或重复奖励。版本 1 存档可迁移到版本 2；损坏或未来版本存档保留原始数据。清除站点数据或换用另一浏览器不会保留旅程。

原创配乐《蕨间灯火》有探索和战斗配器，在首次真实交互后启动，可独立调音量和静音。暂停、后台和静音不会堆叠音符。

## 验证边界

这是完整运行候选。独立审查确认 r9 整体可见改善，但岩石与林缘仍未达到成熟材质目标；真实浏览器 WebGL/GPU 尚未验收，不能称作已完成 Premium 视觉或性能验收。可执行回归使用实际游戏模块、Three.js、GLB、角色关节、RPG/输入/背包/动作和音乐调度；DOM、图片解码和渲染器有明确适配层。

CPU 场景证据读取实际生产几何、镜头和光源快照，并记录固定光照转换和 ACES 色调映射方法。它仍近似光照、材质和透明度，不是浏览器截图，也不能证明真实 GPU 帧率、内存分配、鼠标/触控手感、浏览器布局或扬声器听感。资源数量不等于实测 FPS。生成目标图只是美术参考。

本包只收实际可达运行文件。当前可编辑 Blender 模型、直接重建输入、材料烘焙、原图、音乐源、恢复工具和证据在配套的 r9 可编辑源包。历史 r8 检查点独立保留。
