# 雷霆战机 · 英语风暴

一款把 2D 射击游戏与英语学习结合起来的网页小游戏：**边打飞机，边记单词，边练语法**。

🔗 在线游玩：https://lgch3136.github.io/mini-games/english-thunder-fighter/

## 运行方式

直接用浏览器打开 `index.html` 即可（无需服务器）：

- macOS: `open index.html`
- 或双击 `index.html`

建议使用 Chrome / Edge / Safari 现代浏览器。

## 玩法

1. 屏幕上方会出一道题（单词释义 / 选词填空 / 语法填空）。
2. 4 架敌机身上分别挂着 4 个选项，**击毁携带正确答案的敌机**得分并进入下一题。
3. 击毁错误答案、被敌机撞到、被子弹击中、放走敌机都会扣血；血量归零游戏结束。
4. 连续答对可以积累连击加分；每 6 题升一关（敌人更快、会开火），每 8 题出现一次 BOSS 奖励关。
5. 击毁正确答案的敌机有概率掉落补给：🔥双倍火力 / 🛡护盾 / ❤️回血 / 💣炸弹。

## 操作

| 操作 | 按键 |
| --- | --- |
| 移动 | 鼠标 / 触屏拖动，或 ⬆⬇⬅➡ / WASD |
| 开火 | 自动 |

| 暂停 / 继续 | P 或 Esc |

## 学习内容

- **初级**：小学常见词汇 + 基础语法（be 动词、单复数、时态入门等）
- **中级**：初中词汇 + 核心语法（从句、被动、非谓语入门等）
- **高级**：高中词汇 + 难点语法（虚拟语气、倒装、强调句等）

答对 / 答错后题目栏会显示完整答案（如 `apple = 苹果`、补齐后的句子），帮助即时记忆。

## 文件结构

- `index.html` — 页面结构
- `style.css` — 界面样式
- `data.js` — 题库（词汇 + 语法，可自行增删）
- `game.js` — 游戏引擎（渲染、碰撞、音效、关卡逻辑）
- `assets/` — 战机贴图（PNG + SVG 源文件）；删除后游戏自动回退为矢量绘制

## 自定义题库

直接编辑 `data.js`：
- 词汇格式：`{ en: 'apple', zh: '苹果' }`
- 语法格式：`{ prompt: 'I ___ a student.', options: ['am','is','are','be'], answer: 'am' }`

最高分按难度分别保存在浏览器 localStorage 中。
