让弹球在两座字母阵之间接力

按 C → D → A → O → T → G 击中亮起的字母。暗色字母只反弹，不扣分。接住挡板中央，累计 3 次获得一次召回。

开启加旋：接球瞬间左右移动挡板，会在原接触角度上增加同向偏转；停住后不加旋。球速、生命和召回不变。接球后，挡板旁短线显示这一次反弹方向：金色实线是加旋后方向，灰色虚线是未加旋对照；无旋时显示青色实线。短线不预告后续碰墙或撞砖。
