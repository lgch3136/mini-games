# 字母花园 · WORD SNAKE

[在线游玩](https://lgch3136.github.io/mini-games/english-word-snake/?v=20260912-garden-r4)

2026-09-12 重做移动、输入、渲染和玩法。不是在旧版逐节插值上继续叠加特效。

## 玩法

- 串起单词：按顺序吃亮起的字母。灰绿色字母是之后的预览，可以穿过，不扣血。顶部持续显示中文和已收集的拼写。
- 答案猎手：阅读完整语法题与选项，去吃对应 A/B/C/D 果实。答错扣分、断连击，但保留正确答案、不扣生命。
- 漫游花园：四边相通；经典挑战：护栏扣生命，并沿边自动转向救回，不会卡在墙上反复扣血。
- 三颗心。撞到身体扣一颗、缩短身体，保护两秒；刚好移走的尾格不算碰撞。
- 每字母增长一格；完成一个词缩短三格，长度最多 34 格。完成不停顿、不强制提速。
- 连续收集间隔不超过 9 秒可积累连击，每 5 连提升倍率，最高 x4。
- 长按空格或触屏冲刺按钮，平滑加速至所选速度的 1.55 倍，冲刺采集字母获得双倍分。冲刺消耗能量，字母补充能量，松开平滑恢复。
- 每完成 3 轮出现 12 秒金果路线；收齐 5 颗恢复一颗心并加 300 分。每 3 个无碰撞、无答错的完整单词获得一层护盾。
- 场地每 3 轮轮换青草、薄荷、金色主题。词库使用打乱的词袋，遍历后才重洗。

## 操作

方向键 / WASD 转向；空格长按冲刺；P / Esc 暂停；H 提示（15 分）。手机用连续滑动或方向按钮，一只手转向、一只手冲刺。触控取消、失焦、切后台会释放按键。

有 5 档独立速度：5、6.5、8、10、12 格/秒，游戏中也能调。词库难度不改变速度。顶部 ✦ 可以切换完整 / 简化动效，初始尊重系统减少动态效果偏好。♪ 控制声音。

## 本地运行

在仓库根目录运行 `python3 -m http.server 4175 --bind 127.0.0.1`，打开 `http://127.0.0.1:4175/english-word-snake/`。ES 模块需要 HTTP 服务，不能双击 file://。

## 实现与验收

- `engine.mjs`：无 DOM 的规则层；120 Hz 固定步长，按网格中心转向。头部已经前进的距离直接可见，身体按同一条连续折线路径取样。
- `render.mjs`：Canvas2D 连续蛇身、果实、少量粒子；网格与植物缓存到离屏画布；DPR 上限 1.75；每个显示帧渲染，不限制为 60 Hz。
- `input.mjs`：最多两个明确转弯，过滤系统重复、输入法和快捷键。连续滑动不要求抬手，方向与冲刺指针相互独立。
- `audio.mjs`：原创五声音阶花园小曲与采集音，复用项目单 AudioContext 音频管理器。暂停与返回菜单停止调度、清空声音、挂起音频。
- `app.mjs`：只读诊断、固定开局网格、响应式展示、HUD、设置和生命周期。旋转屏幕不会重新排列蛇或目标。
- `shared/vocabulary.js`：项目词库，过滤非 3–12 个英文字母及重复词；初级 587、中级 785、高级 913。`data.js` 保留语法题库与备用词库。

规则回归：`node --test tests/snake-garden.test.mjs`。全库回归：`node --test tests/*.test.mjs`。

浏览器验收：`/tests/snake-browser.html`，通过普通键盘 / PointerEvent 驱动真实页面，读取快照但不能写入游戏状态。检查连续采集、冲刺、满额特效、手机布局、暂停 / 恢复 / 退出、帧耗时和资源释放。不是直接调用“吃字母”来伪造通关。

`window.snakeDiagnostics()` 只返回复制的状态，不能改动引擎。帧耗时报告是本机本轮测量，不代表所有设备；应结合真实转向与画面检查。
