# 破晓疾驰 / Apex Drive

Three.js 轻量街机赛车。三条完整路线，漂移竞速 / 道具乱斗各两圈；也可无对手、无限圈练习。默认跟车视角，保留第一人称驾驶舱。

## 开始玩

- 默认自动油门，A D / ← → 转向，S / ↓ 刹车。关闭自动油门后 W / ↑ 加油。
- 带速度入弯，**方向 + Shift** 起漂；反打方向可以修正漂移半径，不会突然反转漂移侧。积出蓝 / 金 / 紫焰后松开 Shift，获得 0.55 / 0.95 / 1.4 秒小喷。
- 漂移同时补充两格氮气。**空格**消耗一格，推进 2.05 秒；长按不反复扣格，氮气还在生效时再按也不会浪费下一格。
- 倒计时最后半秒轻按 W，或轻点手机氮气键，获得完美起步。不是从倒计时开始就一直按住。
- E / Ctrl 使用当前道具，Q 交换两个道具槽。C 或顶部按钮切换镜头。R 回正，P 暂停；随时返回选赛道。
- 手机推荐横屏：左手转向，右手漂移 / 氮气 / 道具。默认自动油门，不需要用第三根手指持续加油。关闭自动油门时出现油门键。

## 这一版的比赛策略

- 竞速赛：弯中集气 → 出弯小喷 → 在长直道使用氮气；尾流、超车也能补充储备。路侧青色条是加速带，需实际压上才生效。
- 道具赛：驶过发光补给箱。追踪光弹攻击前方目标（有预警）；护盾抵挡一次攻击；泡泡陷阱留给后车；超级氮气用于突围。没有目标时光弹保留。
- 来袭提示会区分“当前槽有盾”“备用槽有盾”“正在保护”“没有盾”；攻击只造成短减速，不锁死方向，短暂免疫避免连环控制。
- 对手会变道、避让、使用氮气和道具、在来袭时使用护盾；完赛后驶离且不再堵住终点。休闲 / 俱乐部 / 专家改变实际对手速度。
- 练习模式没有对手、攻击或圈数上限。词汇提示默认关闭，可选择在过圈时顺便看词。

画质可选节能 / 均衡 / 精细。使用 120 Hz 固定模拟、显示帧插值、限额粒子池；菜单 / 暂停 / 后台停止渲染和音频。

这不是商业《跑跑卡丁车》的等量复刻：目前是本地单人与 AI 比赛，没有多人联机、车辆养成、队伍赛或角色授权。借鉴的是竞速和道具策略，模型、音乐和实现继续使用本项目的原创资源。

实现、美术来源：[First Light 说明](../docs/first-person/README.md)。本轮设计依据和实测：[Drift Rally 验收](../docs/first-person/RALLY-QA.md)。
