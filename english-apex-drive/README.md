# 破晓疾驰 / Apex Drive

Three.js 第一人称驾驶舱竞速。三条赛道，2 圈大奖赛和不限圈自由练习。

- W / ↑ 油门，S / ↓ 刹车，A D / ← → 转向。
- 空格加速（同时给油），Shift 手刹，R 或右上角“回正”回到当前路段。
- P 暂停；随时返回选赛道。首次玩建议蔚蓝海岸并保留直线稳定辅助。
- 手机建议横屏，左侧转向、右侧油门/刹车/加速。画质可选节能、均衡、精细。
- 靠近前车尾部可获得尾流并更快补充加速储备；提前刹车比一直按满油门更有效。

实现、美术来源与验证：[First Light 说明](../docs/first-person/README.md)。
