# 团团卡丁 / Mochi Rally · Apex Drive

Three.js 轻量街机赛车。三条完整路线，漂移竞速 / 道具乱斗各两圈；也可无对手、无限圈练习。默认跟车视角，保留第一人称驾驶舱。

## 开始玩

- 默认自动油门，A D / ← → 转向，S / ↓ 刹车。关闭自动油门后 W / ↑ 加油。
- 带速度入弯，**方向 + Shift** 起漂。Shift 是渐进手刹：短按保速、弧线浅，长按甩尾更深、掉速更多。车头、行进方向、回正都有连续过渡，不是换一张漂移姿态。
- **松 Shift → 反打回正 → 松开并重新点 W / ↑**，触发出弯小喷。自动油门只负责前进，不会自动喷射；一直按 W 也不会重复喷。成功回正后约 0.8 秒内可点喷，允许提前约 0.14 秒输入。
- **双喷 / 连喷**：第一段漂移回正时，同向轻点 Shift 接一段小漂，分别用新的油门点按兑现两次小喷。连续有效漂移还能衔接三连喷及以上；不能只靠狂点 W 制造奖励。每段有效漂移最多一次机会，最多暂存两次。
- **断位**：已有漂移中，松 Shift，再反方向轻点 Shift 加速拉正，随后可以点喷。保持同一次 Shift 反打只修正路线，不会突然翻转漂移方向。喷射仍需线路空间，冲上草地或撞车会丢失待喷机会。
- 漂移同时补充两格氮气。**空格**消耗一格，推进 2.05 秒；长按不反复扣格，氮气还在生效时再按也不会浪费下一格。
- 倒计时最后半秒轻按 W，或轻点手机氮气键，获得完美起步。不是从倒计时开始就一直按住。
- E / Ctrl 使用当前道具，Q 交换两个道具槽。C 或顶部按钮切换镜头。R 回正，P 暂停；随时返回选赛道。
- 手机推荐横屏：左手转向，右手漂移 / **小喷** / 氮气 / 道具。独立小喷键一直可见，亮起时松漂并点按；关闭自动油门后此键也负责持续加油。

## 这一版的比赛策略

- 竞速赛：弯中集气 → 出弯小喷 → 在长直道使用氮气；尾流、超车也能补充储备。路侧青色条是加速带，需实际压上才生效。
- 道具赛：驶过发光补给箱。追踪光弹攻击前方目标（有预警）；护盾抵挡一次攻击；泡泡陷阱留给后车；超级氮气用于突围。没有目标时光弹保留。
- 来袭提示会区分“当前槽有盾”“备用槽有盾”“正在保护”“没有盾”；攻击只造成短减速，不锁死方向，短暂免疫避免连环控制。
- 对手会变道、避让、使用氮气和道具、在来袭时使用护盾；完赛后驶离且不再堵住终点。休闲 / 俱乐部 / 专家改变实际对手速度。
- 练习模式没有对手、攻击或圈数上限。词汇提示默认关闭，可选择在过圈时顺便看词。

兔兔驾驶员、短轴距圆角卡丁车、转动的车轮、会随速度和转向轻摆的耳朵，配奶油海岸 / 糖果松岭 / 蜜桃港湾。模型为本项目原生 3D 几何，不使用角色贴片冒充转身；可见轮胎和保险杠对应短车身碰撞范围。

护栏采用真实车身外廓，擦碰会沿墙滑行。上草地会明显减速，但仍可加油转回赛道；正面顶墙后也可以用方向 + 油门脱困，不必依赖回正按钮。

画质可选节能 / 均衡 / 精细。使用 120 Hz 固定模拟、显示帧插值、限额粒子池；菜单 / 暂停 / 后台停止渲染和音频。练习模式有实时按键和小喷窗口提示。

这不是商业《跑跑卡丁车》的等量复刻：目前是本地单人与 AI 比赛，没有多人联机、车辆养成、队伍赛或角色授权。借鉴的是竞速和道具策略，模型、音乐和实现继续使用本项目的原创资源。
