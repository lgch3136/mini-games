# 零界突围 / Signal Strike

Three.js 第一人称城市突围。恢复港口、中庭、核心的三座中继，解除机械守卫。

## 2026-09-28 · 信号光效

命中点出现短促柔光，击破后暖色消散；敌人蓄力与未完成的中继台有局部光晕。光斑参与深度遮挡，不透墙显示；共享透明纹理、48 实例与 24 瞬时光斑硬上限，不新增阴影灯或全屏泛光。切图/退出清空，重复切图释放旧实例缓冲。新增 imagegen 原创概念封面不冒充游戏截图。[素材](../docs/light-pass-20260928/ASSETS.md) · [验收](../docs/light-pass-20260928/QA.md)。

- WASD 移动，鼠标瞄准，左键射击，右键精瞄。
- Q / 1 / 2 切换步枪与霰射，R 换弹，空格跳跃，Shift 突进。
- 清除本区防御后，靠近金色中继台并按住 E 接入。
- 点击画面锁定鼠标；Esc 释放并暂停。如宿主不支持锁定，可按住鼠标拖动，或 ← → 转向、J 射击。
- 手机横屏：左摇杆移动，右拇指按住开火并拖动瞄准；单独滑动瞄准区可观察而不开火。
- 受伤时利用掩体；敌人开火前有收缩的蓄力环和提示声。弹丸可以躲开，突进提供短暂无敌而非永久免伤。
