# 贪吃蛇背单词 · WORD SNAKE

一款把经典贪吃蛇与英语学习结合起来的网页小游戏：**蛇形走位，吃掉字母，拼出单词，攻克语法**。

## 运行方式

直接用浏览器打开 `index.html` 即可（无需服务器）：

- macOS: `open index.html`
- 或双击 `index.html`

## 玩法

两种模式（主菜单可选）：

1. **🔤 拼单词**：顶部显示中文释义（每词开头会闪现英文），地图上散落字母块，控制贪吃蛇**按顺序**吃掉字母拼出单词。吃错字母、顺序不对都会扣血。
2. **✅ 选词填空**：顶部显示题目（语法填空 / 中文选英文），吃掉写着**正确答案**的方块。

通用规则：

- 共 3 条命 ❤️：吃错方块 -1，撞到自己 -1（并变短），命用完游戏结束。
- 地图边界可穿越（从一侧穿到另一侧）。
- 💡 H 键提示：拼单词模式显示单词并高亮下一个字母；选词模式排除一个错误选项（扣 20 分）。
- 补给方块：⭐加分 · ❤️回血 · 🐢减速 · ✂️变短。
- 每完成 5 个单词升一关：速度加快并回复 1 条命。
- 连续吃对可积累连击加分，最高分按模式+难度保存在浏览器 localStorage。

## 文件结构

- `index.html` — 页面结构
- `style.css` — 界面样式
- `data.js` — 题库（词汇 + 语法，与《雷霆战机·英语风暴》共用结构，可自行增删）
- `game.js` — 游戏引擎（网格、碰撞、音效、关卡逻辑）
- `assets/logo.png` — 菜单 Logo（由 Codex 图像生成；删除后自动隐藏）

## 自定义题库

直接编辑 `data.js`：
- 词汇格式：`{ en: 'apple', zh: '苹果' }`（拼单词模式会使用 3~9 个字母的单词）
- 语法格式：`{ prompt: 'I ___ a student.', options: ['am','is','are','be'], answer: 'am' }`
