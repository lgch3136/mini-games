让弹球在两座字母阵之间接力

按 C → D → A → O → T → G 击中亮起的字母。暗色字母只反弹，不扣分。接住挡板中央，有奖板心累计 3 次获得一次召回。

开启加旋：接球瞬间左右移动挡板，会在原接触角度上增加同向偏转；停住后不加旋。球速、生命和召回不变。接球后，挡板旁短线显示这一次反弹方向：金色实线是加旋后方向，灰色虚线是未加旋对照；无旋时显示青色实线。短线不预告后续碰墙或撞砖。

连击挑战：连续 3 次板心接球，额外获得 60 分及一次召回（库存最多 3 次）。边缘接球、掉球或主动召回会清空当前连击。未开启时仍按累计板心奖励，不要求连续。

r2 奖励额度（累计与连击模式均适用）：每个目标字母最多计 3 次有奖板心，每次 +15 分。用完仍正常反弹、不扣分；收取亮起的字母后额度刷新为 3 次，已有累计/连击进度保留。暂停、掉球和召回不刷新额度；重新短关从新一局开始。本版不改变球路或要求不停移板。
