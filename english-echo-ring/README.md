# 回响边界 · Echo Ring

独立的轻量街机游戏，不替换合集中的其他作品。向圆心射击，在移动中找到射击角度；金色回弹也会伤到玩家。

## 2026-09-28 · 局部回响光

保留柔性流场与原游戏规则，给碰壁、击杀和共鸣加入短促柔光，光晕绘制在危险子弹和敌人下方。共用一张 256 × 256 透明贴图，减弱动态时降低亮度；没有新增全屏模糊或镜头震动。imagegen 原创封面与派生素材见 [资源记录](../docs/light-pass-20260928/ASSETS.md)，本轮检查见 [验收](../docs/light-pass-20260928/QA.md)。

## 2026-09-23 · 柔性流场试版

本轮保留游戏规则、移动响应、弹速、碰撞与得分，专门优化动态质感，不新增人物贴图或 3D 依赖。

- 圆环内部加入 33 × 33 节点的二维弹簧网格：移动留下尾流，穿行收拢局部空间，反弹、击杀和共鸣向外传递涟漪；所有节点回到固定静止位置，不移动镜头。
- 网格只负责表现，绝不改变敌人、子弹、玩家与碰撞坐标。固定步长积分、插值绘制、位移上限 24 世界单位；轻动效将可见网格位移降至 22%。
- 网格线使用相切的二次曲线，发光按八档细分批次绘制；圆边裁剪取消锯齿状断头。手机和节能模式减半网格线密度，不降低输入更新频率。
- 飞行器侧翼与拉伸采用闭式阻尼跟随，瞄准与位移立即生效；尾迹逐渐变细并平滑消退。粒子位置也使用渲染插值，子弹保留清晰的亮色头部。
- 桌面得分、阶段信息移到两侧，扩大圆环；移除战斗中央重复的大分数。设置里可关闭「柔性流场」，也可在同一局按 `V` 实时切换比较，碰撞和进度不受影响。
- 新模拟仅有固定大小数组；尾迹上限 44，粒子与短效数组原位回收。菜单静止、暂停与退出均不运行新增后台循环，退出清空形变能量。
- 环境网格使用最高 640 × 640 的独立 Canvas 图层合成，避免按全屏 Retina 像素反复栅格化；角色、子弹、外圈、文字不降分辨率。

动态参考：[Tak 的 Neon Gravity 视频](https://x.com/cherry_mx_reds/status/2102529784131600745)。参考可观察的空间受力与回弹关系；本实现为原创弹簧网格，未获取或复制原作代码。公开试玩页受安全验证阻挡，不声称实测过原作输入手感。

## 参考与边界

- 玩法灵感：[Mors — dead_center](https://mors-games.itch.io/dead-center)、[用户提供的视频](https://x.com/MorsGames/status/2095907754657432020)。只向圆心射击，让玩家自己制造的回弹形成风险。原作代码、素材、音乐均未下载或复制。
- 波纹思路：[作者关于数学线段波动的说明](https://x.com/MorsGames/status/2095933252330496046)。本作独立实现 192 节点的阻尼波动膜、周期邻接、固定步长数值积分和闭合二次曲线渲染。
- 动态视觉参考：[Tak 的 INKFALL 视频](https://x.com/cherry_mx_reds/status/2096332308785561652)。借鉴的是统一线条、局部命中反馈、短拖尾、干净的特效消散，不复制其纸张场景、角色或招式。飞行器侧翼随切向速度轻微形变，穿行拉伸与残像、命中亮点→细环→墨粒共用事件时间；不引入全屏闪白、镜头震动或 hit-stop。

## 规则与操作

- `WASD` / 方向键移动；`J` / 空格 / 鼠标左键按住开火。
- `Shift` / `K` 穿行：0.16 秒，2.6 秒冷却。只在穿行中免疫碰撞，不是永久护盾。
- `P` / `Esc` 暂停；顶部始终有暂停与退出按钮。
- 手机左侧摇杆移动，右侧独立开火与穿行，支持同时按住。单指释放不会干扰另一个手指。
- 青色出射安全，碰壁后变金色，对敌我双方都有效。第三次碰壁消失；子弹最多 18 发。
- 每次击杀积累 12.5% 共鸣，擦弹增加 8%。充满后清除场上的危险回弹，4 秒得分翻倍。受伤降低共鸣并清除回弹，提供 1.8 秒恢复保护。
- 4.2 秒内连续击杀累积连击；每 5 连击增加倍率，上限 5 倍。回弹击杀基础 150 分，直接击杀 100 分；擦弹每弹只计一次。
- 普通追踪者、绕行者、双血分裂者逐步加入。敌人有 0.95 秒出场预告，分裂子体也有安全预告。连续出场有强弱呼吸节奏，不清空战场等下一波；无固定终点。
- 「回响」3 格护盾；「一线」一击结束。两种模式本机最佳分数分开保存。
- 本作专注纯街机操作，不插入单词答题或学习弹窗。

## 工程与资源

- 原生 Canvas 2D、原生 ES Modules，无构建、无 CDN、无运行时外部网络依赖。
- 120 Hz 固定模拟 + 渲染插值；方向输入保留极短按键，反向优先最近按下的方向，别名按键独立释放。
- 移动碰撞边界为稳定圆，不跟着装饰波纹抖动。波纹幅度被限制在 16 世界单位以内，角色保留可见安全余量。
- 相对扫掠检测防止快速弹丸穿透移动目标；墙面求交后仅反射剩余帧距离，不减速、不传送。
- 光晕预烘成小 Canvas，避免逐帧高开销模糊；背景只在布局改变时绘制；实体、粒子、效果、拖尾、音频声部均有上限。
- 原创 104 BPM D 小调色彩配乐，击杀音按五声音阶上行；复用项目已有的有界音频生命周期，不复用音乐旋律。未使用商业录音或采样。
- 菜单静止时无 RAF；点击菜单圆环可激起一段 2 秒波纹，结束后停止。暂停、失焦、切后台或退出停止 RAF、音频定时器与所有声部；离开页面销毁监听器和音频上下文。
- 提供轻动效、节能渲染，自动尊重系统减弱动态效果偏好。

## 可复验

```sh
node --test tests/echo-ring.test.mjs tests/echo-field.test.mjs
python3 -m http.server 4173 --bind 127.0.0.1
```

`tests/echo-browser.html` 使用正式页面，注入普通键盘/多指事件，再读取只读 `echoDiagnostics()`。正常输入回放不修改生命、分数、位置、敌人或时间。单元压力测试会明确续补保护状态以运行 10 分钟，不能用它证明玩家可以无伤通关。

测试覆盖短按、反向、停止、连发、穿行、出场预告、扫掠碰撞、反弹速度守恒、擦弹去重、共鸣、分裂、死亡终态、波纹传播与衰减、确定性重放、集合边界、暂停/退出资源释放。自动测试只能验证这些性质，不等同于主观趣味性已达到某款商业游戏的水平。

发布前的浏览器尺寸、性能记录和实机画面见 `verification.md` / `assets/`。
