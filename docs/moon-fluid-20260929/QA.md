# 月影忍途：帧节奏、连续动作与资源回收

版本 `20260929-fluid-r2`。本文件保留发布前的本地验收记录，线上发布状态以仓库的 GitHub Pages 部署记录为准。

## 资源排查

- 起始进程快照曾见 Codex 主界面渲染进程约 73% CPU、Chrome 某页面进程约 72% CPU。约一分钟后的快照分别回落至 2.5% / 0.1%。这是瞬时负载，不是泄漏证据，未擅自结束这些用户进程。
- 开始排查时，Codex 内置 Browser 没有任何游戏标签。没有遗留无头 Chrome、FFmpeg 或 Blender 渲染任务。
- 本轮服务器 PID 43610、端口 4196，起始约 20 MB RSS / 0% CPU。32 GB 系统未使用 swap；不能把高常驻内存本身直接判成泄漏。
- 机器有 Intel UHD 630 和 AMD Radeon Pro 5300M。此前游戏明确指定 `powerPreference: low-power`；网页实际报告为 Intel UHD 630。

## 复现出的缺陷

1. 1920 × 1080 浏览器（游戏 iframe 1920 × 1034）、全特效、DPR 1：修改前 24 秒往返回放帧间隔中位数 17 ms，但 **P95 34 ms**。只报中位数明显不足。
2. 敌人整个 strike 阶段强制使用攻击第 8 帧。离线采样 12 帧只得到 **1 个不同的手部姿势**。
3. 旧跑步距离相位在 7.5 单位 / 秒时约 **4.32 个完整步态周期 / 秒**；慢速敌人又把整套腿部动作仅混合约三分之一，脚落地与身体推进不同步。
4. 刀光一帧只存一个端点；掉到 30 fps 时短刀弧只剩少量折点。
5. 密集屋顶和门窗装饰为整章单批次，远离屏幕的三角形仍被提交。

## 修改

- 跑步保持原移动速度 / 反向响应，调整步长与腾空比例，完整冲刺步态约 2.67 周期 / 秒。慢速敌人的腿部完整摆动，步相按真实位移推进，落地脚相对地面固定。
- 敌人根据真实状态倒计时连续采样蓄力、出刀和收势，并插值半个逻辑帧的姿态；未延迟输入或改写敌人碰撞窗口。
- 刀光沿刀刃扫过的弧形以 180 Hz 补样，24 个预分配节点、有界衰减；属于显示补样，不增加伤害范围或修改命中规则。
- 只对密集、静态实例按空间分批；同样的模型顶点、纹理、画布分辨率。初始场景提交三角形从 58,038 降至 26,070；回放末尾从 52,672 降至 20,704。
- 新增实际平均 RAF 频率、P99、最坏帧、超过 25 / 34 / 50 ms 的计数和丢失 60 Hz 刷新机会估计。仅诊断模式启用异步 GPU 计时；不使用 `gl.finish` 或像素读回来测性能。
- 离开页面时显式释放 WebGL context，测试回放加入 45 秒墙钟上限，失败不再无限等待逻辑帧。

## 中途结果（不是最终通过声明）

空间裁剪和动作修改后第一次 24 秒回放：1124 个样本，平均 RAF 46.96 Hz，中位数 16.9 ms，P95 34.1 ms，P99 50.1 ms，最坏 82.4 ms，286 帧超过 25 ms。三角形减少并没有单独解决帧节奏问题，因此继续排查 GPU / 合成。

冷启动测试还暴露了新增计时插值中 `old` 为空、且两个 state 都 undefined 时错误进入分支的问题。已停止异常回放、修正显式空值检查，并新增冷启动回归。步态测试使用浮点容差验证落脚，而不是要求浮点结果严格等于零。

## 同条件显卡策略对照

两轮都使用本轮相同代码 / 几何、1920 × 1080 浏览器、1920 × 1034 游戏 iframe、DPR 1、全特效、普通输入往返回放。每轮开始后安静等待 26 秒，不在中间截图或运行其他测试。系统其他应用仍在，不是隔离实验室。

| 指标 | 强制低功耗 Intel UHD 630 | 高性能 AMD Radeon Pro 5300M |
| --- | ---: | ---: |
| 平均 RAF 回调频率 | 47.43 Hz | 58.06 Hz |
| 中位帧间隔 | 17.0 ms | 16.7 ms |
| P95 帧间隔 | 34.5 ms | 18.6 ms |
| P99 帧间隔 | 49.1 ms | 33.5 ms |
| 最坏帧 | 81.9 ms | 50.9 ms |
| >25 ms 样本 | 281 / 1135（24.8%） | 38 / 1200（3.2%） |
| GPU 绘制中位耗时 | 7.09 ms | 0.98 ms |
| GPU 绘制 P95 | 8.99 ms | 1.58 ms |

最终保留 `high-performance`，这是 WebGL 上下文偏好，不是修改 macOS 或 Chrome 全局设置。双显卡机器会提高运行时功耗；页面隐藏暂停，离开页面显式释放 context。没有改变分辨率上限、关闭抗锯齿或删减角色顶点。GPU 探针只包围 WebGL draw，不包含 Canvas2D / 浏览器合成；RAF 频率也不是显示器光学测得的呈现频率。AMD 路径仍有少量长帧，不宣称稳定锁定 60 fps。
