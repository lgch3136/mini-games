重建日期：2026-09-05。实际范围为 `english-temple-dash/`；不把本轮验收外推到尚未重建的其他游戏。

这一轮重写模拟、输入、绘制、菜单和配乐，保留原网址与项目词库。玩法参考 [Imangi 的 Temple Run 2 官方介绍](https://imangistudios.com/thegames/temple-run-2/) 中“奔跑、跳跃、滑行与不同环境”的组合，但没有复制商业角色、关卡、ROM 或音乐。目标是先让路线可判断、动作连续、结果可信，不声称拥有原作的全部系统与内容。

## 这次不是只换分辨率

| 原问题 | 当前实现与检查 |
| --- | --- |
| 近身障碍减速，距离无法估计 | 所有场景、地面与障碍共用线性距离投影；等距离对应等像素移动；碰撞发生在脚下，不是提前数米 |
| 换道迟钝 | 120 Hz 固定步进，渲染插值；换道首步响应、约 140 ms 收束；手指滑过 19 CSS px 即触发，不等待抬手 |
| 受伤后画面跳动 | 不震屏、不改跑速、不搬动摄像机或人物；短暂动作受力和音效说明伤害 |
| 动画像漂移贴纸 | 正后方关节跑者、随路程推进的步态、空中收腿、滑行动作；矿车轮距与轨道对齐，乘车时不继续跑腿 |
| 路面与危险混在一起 | 浅砂岩地面、蓝青实心障碍、棕色低栏/横梁、实际桥面缺口；装饰不横穿操作视线 |
| 每轮同样的小模板 | 18 组编排，洗牌、镜像；庭院/悬桥/矿道有不同模板池；每 480 m 进入下一段；分叉选择影响后续新生成路段 |
| 只有距离增长 | 连续穿越、精准跳滑、风行无伤/吸附/双倍分、磁力与护符；成词恢复生命并补充护符；结算记录里程、连击与单词 |
| 手机只能靠按键或抬手操作 | 四向即时轻扫、点击跳跃、左右与跳滑四个独立触屏键；暂停、失焦、取消触点均清空输入 |
| 暂停仍耗资源或恢复无声 | 菜单/暂停/结算停止 RAF、断开音源、停调度并挂起音频；异步 suspend/resume 串行化，验证快速反复暂停后的真正恢复 |

跑速为 0.70/0.85/1.00/1.15/1.30/1.50×，可以在暂停中调整。难度控制机关间距与词库，不偷偷自动加速。相同种子可重跑练习，新路线会换种子。特效随机源与地形随机源分离，拾取一枚金币不会意外改变后面的道路。

路线不是无限种原创关卡：它是有限的 18 组模板在三类环境中持续组合。矿车段改变载具表现、轨道及障碍组合，仍使用同一套易懂的换道/跳跃/滑行输入，不是完整的独立矿车物理游戏。

## 可复现验收

```sh
node --test tests/temple-wind.test.mjs
node --test english-word-ranger/tests/engine.test.mjs
python3 -m http.server 4173 --bind 127.0.0.1
```

- 引擎 12 项：首步响应、跳滑/空中下落、实际位置碰撞、脚下接触、错误动作受伤、逐字拼词、同种子重试、分叉稳定性、暂停调速等。
- 长跑 216 组：12 个种子 × 6 档跑速 × 3 档难度，每组 160 秒。累计 34,560 秒模拟、973,440 米、0 次损血，覆盖三种场景；活动道路、奖励、粒子均有上限。
- pilot 只提交正常方向/跳跃/滑行输入，不改位置、血量、无敌时间或碰撞。它能读取场景，测试证明可达与回归稳定，不等于普通玩家体验，更不能证明已达到原作趣味性。
- 浏览器 `/tests/temple-ui.html` 检查正式页面的 22 项输入与生命周期行为。
- `/tests/temple-playback.html?stop=43` 用真实 RAF 播放同一引擎、绘制器和音频；可暂停、半速、单步。43 秒正常输入经过庭院、悬桥并进入矿道，保持正常生命。

浏览器测量、已修复的验收问题和响应式截图见 [browser-results.md](browser-results.md)。性能数字仅代表当前 macOS 内置 Browser，不代表低端真机，也不把 JavaScript 工作时长当作系统总 CPU/GPU 占用。

## 素材与声音

Imagegen 生成了谷地、砂岩地面、矿洞远景，完整提示词与路径见 [ART-PROVENANCE.md](ART-PROVENANCE.md)。角色、载具、机关、轨道、词印与 UI 由正式绘制器实时绘制，没有使用旧版贴图裁剪动画。合集封面来自实景回放，不是与游戏不符的宣传图。

新配乐为原创 112 BPM、32 小节的合成乐曲，以柔和拨弦、旋律与轻打击组合，按音频时钟预排；不同环境及风行状态改变配器。跳跃、滑行、落地、拾取、成词、受伤和护符破裂有独立反馈。复用 Word Ranger 的有界音源基础，不使用其旋律，也不再叠加旧版的两套音乐系统。
