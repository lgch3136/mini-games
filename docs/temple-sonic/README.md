# 遗迹词途 · 音速远征

2026-09-05。本轮仅优化 `english-temple-dash/`，并更新其大厅入口；不把结果外推到其他游戏。

## 这次改变了什么

- 原 Canvas 2D 的混合透视绘制被真实 Three.js / WebGL 正交场景替换。角色、路面、障碍和阴影共享坐标、尺寸和深度测试。每个顶点匀速移动；接近人物时不缩放、不压扁，也不换用另一条运动曲线。
- 默认是独立的节奏轮滑模式：完整钢琴曲、单方向、双方向组合、长按滑行／侧滑、判定与连击。原自由跑酷仍可选择。
- 节奏谱不是随机刷怪。三个曲目的真实旋律起拍产生机关头点，保留休止，按段落增加组合和长条；音乐保留左右手和弦与时值。原谱的动态速度在本作改为恒定基础 BPM，属于定速游戏编曲。
- 8 拍预备；音乐、绘制目标、输入判定共用 AudioContext 时钟。`scoreTime × 26` 是唯一前进距离，120 Hz 模拟跟随它，绘制插值。长于 300 ms 的异常停顿会暂停，不能静默积累音画错位。
- 人眼判定也要一致：箭头中心、长条尾端和金色判定轨使用同一个 `CUE_HEIGHT / CUE_FRONT`；轨道位于站立角色轮廓前方。音乐拍点与世界坐标之间只留固定 0.28 谱面秒（1× 时 280 ms）的动作提前量，以便跳跃顶点跨过实物。箭头注释不被其背后的立体底板裁切。
- 失误真实记入准确率，但不中断整曲、不甩镜头、不减速。40 连击获得一枚保护胶囊（最多 3），只保护连击，不篡改准确率。满能量按 Ctrl / 屏幕按钮开启 6.5 秒双倍得分，速度不变。
- 每正确完成 6 拍获得项目词库的一个字母；拼写浮层与动作区分离。随时结束查看判定统计、最高连击和已学单词；曲终可继续循环。
- 0.70 / 0.85 / 1.00 / 1.15 / 1.30 / 1.50 六档速度，暂停时调整。音乐事件间隔同步变速但音高不变。±150 ms 校准按真实毫秒计量，不随倍速改变单位。
- 角色轮滑推蹬、连续跳跃衔接、空中俯冲；自由模式修正原来的过高步频和足部滑动。真正切开的断桥、可见的跳跃宝箱、即时生效的分岔奖励与更多人工节奏段。

## 对标的证据与边界

[R2Beat 官方介绍](https://r2beat.pmang.jp/notices/8) 明确结合轮滑、按音乐节奏避障与多种路线。本作据此从自由跑酷拆出节奏玩法；没有复制商业音乐或角色，也不声称仅凭自动测试已达到原作全部内容和手感。

[Three.js 正交相机](https://threejs.org/docs/pages/OrthographicCamera.html) 用于保持距离无关的尺寸；[InstancedMesh](https://threejs.org/docs/pages/InstancedMesh.html) 批量绘制重复几何；按[资源清理文档](https://threejs.org/manual/en/cleanup.html) 释放材质、纹理、几何和渲染器。部署内置固定版本依赖，不走运行时 CDN。

画面目前是统一的低多边形 3D 美术，不是 QQ 音速原版角色精度或内容规模；没有联机竞赛、道具对战、商业曲库。本轮验收关注线性运动、真实节拍、可读性与资源生命周期，不能用测试通过数替代玩家体验。

## 可复现验收

```sh
node --test tests/temple-wind.test.mjs tests/temple-rhythm.test.mjs
python3 -m http.server 4173 --bind 127.0.0.1
```

- `/tests/temple-ui.html`：真实自由模式的输入、触屏、暂停、重启、尺寸与资源边界回归。
- `/tests/temple-sonic.html?track=prelude145&level=hard`：正常键盘事件播放整首 145 BPM 乐曲；点击第二个回归按钮检查切速与音频生命周期。
- `/tests/temple-sonic.html?track=turkish120&level=normal&input=touch&stop=55&clean`：触屏按键的双指组合与长按；不改坐标、生命、谱面或时钟。播放完自动暂停并清空音源。
- `/tests/temple-playback.html`：自由模式共享引擎与绘制器的暂停、单步、慢速观察；可检查跳滑与断桥接触。
- `window.templeDiagnostics()` 只读输出构建号、音频时钟、判定、输入队列、画布尺寸、CPU 帧工作时间、绘制调用、纹理及几何计数。

截图与机器结果见 `browser-results.md`。资源出处见 `../../english-temple-dash/CREDITS.md`。
