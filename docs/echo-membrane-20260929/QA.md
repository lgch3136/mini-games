# 回响边界 · 光学薄膜验收

版本：`20260929-membrane-r1`。范围仅限回响边界的表现层、降级路径与验证工具；不修改 `sim.mjs`、`input.mjs`、`audio.mjs`，不改变玩法、相机或难度。原有两段未跟踪的月影录屏不纳入本次发布。

## 实现

参考用户给出的 [Mato 原帖](https://x.com/MatoToushi/status/2104778232683999363) 和作者的 [pururu 演示](https://pururu-slime.matodesign.workers.dev/)。学习的是受力形变与材质联动的原理，新增代码为独立实现，没有拷贝作者的源码、素材或音频。

1. 在既有 33 × 33 节点上增加有界高度场：接触下陷、波动传播、阻尼恢复。渲染插值不改变游戏位置。
2. 同一场驱动法线高光、轻微聚光和底部细网格折射；边缘厚度与外圈共用边界数据。测试时发现早期厚边没有同步波纹，已合并到同一条边界。
3. 单个 WebGL 1 三角形，2 张数据纹理共 5,380 字节，材质图最多 512 × 512。不使用全屏后处理、实时镜面场景或三维模型。5,380 字节不代表总显存：另有输出画布和原 Canvas 图层。
4. 纯 Canvas 节能路径、WebGL 初始化失败回退、上下文丢失回退与恢复；暂停无新增调度，销毁主动删除 GPU 资源并释放上下文。

## 固定场景 A/B

本机 Codex 内置 Browser，1280 × 720，同种子 20260929，同一策略每 4 个 120 Hz 模拟步产生一次普通输入，30 秒共 3,600 步。旧版为发布提交 `93add20` 的渲染器；两次均完整动效，没有降分辨率绘制弹头和玩家。

| 指标 | 升级前 | 升级后 |
| --- | ---: | ---: |
| 帧间隔中位数 | 16.7 ms | 16.7 ms |
| 帧间隔 P95 | 18.2 ms | 17.7 ms |
| 帧间隔 P99 | 18.5 ms | 18.4 ms |
| 大于 24 ms 的帧 | 0 | 0 |
| JS 提交工作 P95 | 1.2 ms | 1.1 ms |
| 最终得分 / 击杀 / 发射 | 5225 / 15 / 125 | 5225 / 15 / 125 |

**两个最终模拟快照逐字段序列化完全一致**，包括玩家、敌人和全部子弹位置，不仅仅是分数相同。正式模拟模块没有修改。帧间隔分位数覆盖预热 1 秒之后的整段回放；JS 工作包括模拟和提交，不是完整 GPU 用时。小幅差异属于单机样本波动，不能宣称优化了固定百分比，也不能推断所有手机都为 60 FPS。

## 检查记录

- 全仓 Node 测试：392 / 392 通过。
- 本作模拟、输入、波动、16-bit 纹理、周期边界、GPU 资源生命周期：31 / 31 通过。
- 正式页面桌面检查：30 / 30 通过，覆盖完整和轻动效。
- 390 × 844 触控模拟：35 / 35 通过，含双指移动/开火、单指释放、取消与暂停恢复；无横向溢出。它不是实体手机性能测试。
- 真实 WebGL 上下文丢失→Canvas 回退→恢复材质：通过，游戏快照未改变。销毁后数据纹理存储 0，绘制通道 0；重复销毁安全。
- 正式游戏 90 秒完整动效正常输入回放通过：5,390 帧，最终模拟时间 89.99 秒，到达第四阶段，峰值 17 子弹 / 11 敌人，材质节点始终 1,089；超过 24 ms 的帧 1。尾段 240 帧窗口中位数 16.6 ms、P95 18.4 ms、提交工作 P95 1.6 ms。退出后 RAF 停止，声音、音乐定时器、粒子、短效、尾迹、平面形变与高度场全部归零。静止菜单保留一张材质预览，但不继续上传纹理或绘制。

- 不可创建 WebGL 与纯 Canvas 节能路径分别完成 10 秒 / 1,200 步回放，两份最终模拟快照一致，均无 GPU 绘制；不是将游戏停在错误提示页。
- 测试浏览器记录了一条此前也出现过的 `MutationObserver.observe` 异常，日志没有游戏模块定位；本作和这两个测试页未使用这个 API。不能称为「控制台零错误」，但当前正式启动、输入、完整回放、暂停、重开与退出检查均通过。

## 复验

```sh
node --test tests/echo-ring.test.mjs tests/echo-field.test.mjs tests/echo-surface.test.mjs
python3 -m http.server 4197 --bind 127.0.0.1
```

- `/tests/echo-browser.html`：正式页面输入与资源检查、90 秒正常输入回放。
- `/tests/echo-material.html`：固定场景；`?stop=10&fallback=1` 模拟无法创建 WebGL；`?stop=10&economy=1` 检查节能路径。
- 材质对比台的 WebGL 故障注入只存在于测试文件，不修改系统硬件加速，不注入正式游戏的生命、分数或位置。
