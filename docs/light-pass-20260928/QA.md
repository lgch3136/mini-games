### 验收中发现的问题与处理

- 初始赛车运行出现 WebGL context lost/restored，测试自动暂停，**未计为通过**。将光斑颜色缓冲预先分配、固定属性布局，并让透明平面使用单次正反面渲染；本地预览还命中了旧缓存，随后关闭测试缓存重新载入。新版左右深漂与完整两圈均通过，未再复现。不能仅凭这次复测断言所有驱动层 context loss 的根因均已解决。
- 射击冷启动/首次地图编译会占用首帧；旧测试用 450 ms 墙钟时间等待，实际模拟尚不足 450 ms。改为正式输入持续到模拟确实前进 450 ms（5 秒超时），仍然依赖真实 RAF，不跳帧、不改时钟；原移动、射击与布局断言保持不变。
- 回响边界首次极短键检查未通过，未修改其输入逻辑或断言；使用较轻的页面观测重新执行，完整 27 项通过。短按丢失性质另有单元测试验证，单次失败不隐去。
- 浏览器控制日志中出现过无源文件定位的 MutationObserver 报错；未将工具日志空白作为游戏通过依据。
