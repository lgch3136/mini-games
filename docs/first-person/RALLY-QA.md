# Drift Rally · 2026-09-08

目标是把原本“沿路开车”的 Apex Drive 改成有漂移收益与攻防选择的街机比赛，不以增加贴图或降低分辨率代替玩法改善。

## 对照依据

- [世纪天成：模式介绍](https://popkart.tiancity.com/homepage/v3/guide/mode.html)：竞速与道具赛分别强调驾驶技术、道具策略。本项目因此拆成两种模式，而不是在同一玩法里无区别地堆攻击物。
- [世纪天成：新手指南](https://popkart.tiancity.com/homepage/v2/guide/beginner.html)：方向、漂移、道具等独立操作。手机默认自动油门，仍保留转向与漂移 / 道具的独立手指。
- [世纪天成：教学专区](https://popkart.tiancity.com/homepage/v2/community/education.html)：路线、漂移与喷射技巧形成技术层次。本项目采用自己的三阶集气与松键小喷规则，不宣称其数值等于原作。

## 核心改变与纠错

1. 车身朝向和实际行进方向分离；漂移保持起漂侧，反打只改变弧线。输入不等待镜头追上，位置和朝向按显示帧插值。
2. 漂移必须带速度、在路面且总体向前；静止按键和原地画圈不能获得小喷。蓝 / 金 / 紫三阶，短弯也有低阶收益。离开路面或碰撞取消奖励。
3. 两格氮气按次消耗；保持空格不自动耗尽库存，推进期间再按不会浪费下一格。补给加速带、尾流和超车提供线路选择。
4. 两槽道具、基于名次的补给概率，避免两个护盾堵死库存。追踪弹有至少 0.55 秒预警；近距离不穿到车前再反向命中，远距离能够在存活时间内追上行驶目标。
5. 来袭提示匹配实际库存；护盾、短暂受击免疫和保持转向构成反制。对手会保存护盾应对攻击，安全变道，避免不停切进玩家车身。
6. 完赛 AI 不再作为实心障碍停在终点。这是完整路线回归发现并修复的问题，不是跳过检测门来通过测试。
7. 默认跟车、可切驾驶舱；可见胎痕、分阶火花、对手氮气和护盾；速度表避开桌面车尾。天空改为方向空间渐变 / 云层，完整转圈没有全景贴图拼接缝。
8. 漂移胎噪、喷射、集气档位、拾取、格挡和命中各有声音反馈。连续胎噪只有一个可停止的循环源，不为每帧新建声音。
9. 实例化池有固定上限：96 火花、180 胎痕、50 道具实体；重新发车时释放旧实例缓冲。场景几何和原有模型纹理复用。静态景物按 128 米分区合批，视锥和阴影视锥可以剔除不用绘制的路段；没有减少场景内容或降低游戏分辨率。

## 验收边界

测试环境为这台 Mac 上的 Codex 内置 Browser。手机为尺寸与触控模拟，不冒充实体手机测试；帧工作耗时是 JavaScript 模拟和渲染提交，不等于 GPU 时间。短小输入测试含场景重建，不能用其 6 帧样本声称流畅度。

自动驾驶控制器能读取路线并精确操作，通关速度和名次不是普通玩家难度研究。规则与完整流程通过，也不意味着已经达到商业《跑跑卡丁车》的内容规模或得到玩家对趣味性的认可。目前仍为单人对 AI、三条路线，无联机与养成。本轮优先兑现漂移手感、出弯收益、道具反制和资源稳定。
