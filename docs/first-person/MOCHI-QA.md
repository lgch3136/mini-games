# Mochi Rally · 2026-09-08

版本：`20260908-mochi-r1`。本轮针对 Shift 按键时长、出弯点油门、连喷 / 断位和萌系画风重做。它是原创的街机物理实现，不声称取得了 Nexon 私有物理参数或精确复刻原作。

## 依据与机制

- [世纪天成教学专区](https://popkart.tiancity.com/homepage/v2/community/education.html) 将线路与优化漂移作为进一步学习喷射技巧的基础。
- [2006 年官方操作说明的 52PK 转载](https://popkart.52pk.com/popkart_wenzhang/20060323/56173.html) 明确区分方向、油门与 Shift，并说明按住 Shift 的时长影响漂移。来源页面标注“官方”，这是操作说明，不是原始物理源码。
- [17173 玩家技巧讲解](https://news.17173.com/z/popkart/content/2007-02-13/1171377429.shtml) 展示优化漂移、反打、再次按油门、连喷和反向点 Shift 的输入顺序。这是社区的操作经验，不当作官方参数表。

这次不再用“松 Shift 自动奖励一段加速”代替操作技巧：

1. **渐进手刹**：Shift 持续时间影响车身转动、侧滑与减速；短按保速、长按更深。方向、速度向量、角速度均连续。
2. **回正阶段**：松 Shift 后进入 recover，而非立刻清零滑移。反打逐步拉正，重新抓地不会跳变位置或把车头贴到速度方向。
3. **点按小喷**：有效漂移积出一次约 0.8 秒的点喷窗口；油门必须产生新按下边沿。自动油门不等于点按，一直保持 W 不会自动喷。140ms 的短输入缓冲接受略早的点按。
4. **双喷 / 连喷**：同向追加一段小漂可以保留前一个机会；每个有效漂移最多一个机会，最多暂存两个。喷射间隔形成连续衔接；重复乱点不能凭空得分。
5. **断位**：有效漂移后松 Shift，再反向点 Shift，连续加快车头拉正，可接小喷；一直按同一次 Shift 再反打只改变弧线。
6. **动量连续**：小喷结束后渐进回落到巡航速度，不再瞬间把超速裁掉。碰撞、草地与回正重置会取消待喷机会。

数值是针对本项目道路宽度、相机与速度尺度调校的原创规则。连喷仍要有线路空间：错误方向连续喷射会冲出路面，而不是“按对按键就无条件奖励”。

## 视觉与性能

- 真实 3D 兔兔、圆角短轴距卡丁车、棉尾巴、耳朵、腮红、轮毂；轮胎转动、前轮转向、头部受力与耳朵轻摆分别驱动，不是贴图平移。
- 奶油海岸 / 糖果松岭 / 蜜桃港湾使用统一浅色路面、糖果护栏和圆润树冠；UI 同步改为奶油 / 薄荷色。菜单是静态正面三分之四镜头，不运行菜单动画循环。
- 固定模型细节使用顶点色合批，整车最多 12 个网格；保留不同关节独立运动。动画节点使用弱引用缓存，不每帧遍历模型查找。删除对旧天空 / 水泥贴图的无用预加载，不删除其他游戏仍使用的原文件。
- 最近路段查询预计算不变的路段数据、比较平方距离，最后只分配一个结果。旧版在遍历过程中反复开根号并创建“暂时最近”对象，后半段赛道会产生尤其多的垃圾。三条赛道上的道路内外 720 个取样与旧算法逐字段一致。
- 保持 120Hz 固定模拟和渲染插值，没有通过降低分辨率冒充流畅度优化。模型尺寸与碰撞范围一起调整，旧长车身测试不再硬套短卡丁车。
- 实机检查补上护栏边界：绘制和碰撞共用同一护栏尺寸，按车身转角计算外廓；擦碰只消除向墙外的速度，保留沿墙滑行。修复草地固定阻力大于起步动力导致的停死，补上低速有动力时的转向响应；顶墙后可通过油门和方向脱困，不必强制按 R。
- 小喷就绪、断位、连喷有独立声音和轻量提示；手机始终有独立小喷键。练习区显示实际按键，而非车轮的滞后角度。

### 性能实测过程（不能冒充跨设备保证）

本机为 Codex 内置 Browser；手机为尺寸与触控模拟，不是实体手机。帧工作时间指 JavaScript 模拟和绘制提交，不是 GPU 时间。

- 合批前海岸道具赛完整两圈 117.14 秒，21 次小喷 / 7 次氮气 / 7 箱补给 / 2 次命中。最后 1200 帧中位数 16.8ms、P95 33.8ms；工作时间 3.9 / 5.9ms。
- 合批后港湾完整竞速 126.74 秒，24 次小喷 / 8 次氮气。此轮中位数 32.6ms、P95 83.4ms，不能称为稳定 60fps。系统同时报告 CPU Speed Limit 28%，随后降至 22%；旧测试的高频分位排序也仍在运行。
