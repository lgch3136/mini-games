# First Light — 两款第一人称新游戏

2026-09-06。原生静态 ES modules / Three.js 0.185.1；沿用 GitHub Pages，不引入打包器或远端运行依赖。

## 设计与参考

- [sadbuck​​et 的载具战斗视频](https://x.com/sadbucketdev/status/2096331267641934266)：实际是第三人称 Bumper & Thumper 载具战斗，并非第一人称赛车。参考的是可读的车辆体积、地形层次和连续运动，不复制它的素材或代码。
- [Techartist 的 FPS 演示](https://x.com/techartist_/status/2096308761535394034)：原帖展示机械地面单位、飞行单位与最终守卫的城市突围。参考空间遮挡、敌人高度变化和近景枪械反馈，重新实现原创中继任务。
- [Three.js：Making a Game](https://threejs.org/manual/en/game.html)：渲染与游戏规则分离；Three 本身不提供碰撞、输入或敌人 AI。
- [Three.js：Optimize Lots of Objects](https://threejs.org/manual/en/optimize-lots-of-objects.html)：合并静态几何，避免每个道具零件各占一次 draw call。

## 破晓疾驰 / Apex Drive

- 驾驶舱透视，不是屏幕坐标缩放假道路。车辆在世界 X/Z 内自由转向；公路样条只用于地图与对手路线。
- 三条闭环赛道，真正的弯道与坡度；两圈大奖赛、五位对手、不限圈的自由练习。
- 速度相关转向锁、刹车、手刹滑移、离路减速、护栏和车辆接触、尾流充能、加速储备和超车奖励。
- 20 个有序检查门验证一圈；过起点必须确实从上圈跨越，不靠停在起点重复记圈。R / 回正不会增加圈数。
- 本地最快圈保存在浏览器本地；不上传数据。

## 零界突围 / Signal Strike

- 120 Hz 固定步长，连续墙面滑动、视角立即响应，显示帧对移动实体插值；鼠标锁定失败时仍可拖动/键盘操作。
- 脉冲步枪与磁轨霰射，射程与散布不同；右键精瞄、弹匣与备弹、换弹中断、短距突进、跳跃。
- 机械爬行者接近与扑击预警；无人机侧移、保持距离；固定炮台蓄力；大型守卫血量过半后加快扇形弹攻击。
- 射线先判断墙体再判断敌人；敌方弹丸采用有限线段检测，不能穿墙或跨帧穿过玩家。
- 港口 / 中庭 / 核心三段推进；清除本区后在金色中继台按住 E 接入，恢复补给、记录检查点并打开下一道门。
- 失败可从最近已恢复的中继继续，早先的敌人不会复活。

## 美术、声音和生命周期

- imagegen 原生工具生成的天空、混凝土材质直接进入 WebGL 场景，非宣传假截图。提示词及来源见 ART-PROMPTS.md。
- Blender 4.5.13 LTS 脚本生成五类原创倒角模型，按材质合并。可用 `build_models.py` 重建；`.blend` 与 `.glb` 都保留。
- Canvas2D 只承担小地图、标牌和缓存微纹理；场景为真实透视 3D。地面/标线/装饰层有明确高度间距。
- 单个 1024 阴影贴图；均衡模式 3D 缓冲区上限为 CSS 像素分辨率，HUD 保持设备原生分辨率。节能模式关闭实时阴影；精细模式上限 DPR 1.5。
- 配乐、引擎、武器、命中、换弹、预警、脚步和奖励音均为本项目原创 Web Audio 合成，非挪用原游戏录音。一个 AudioContext，噪声缓存，声部数量有上限。
- 暂停、退出、页面隐藏与失焦会停 RAF、模拟时钟、音乐定时器、引擎和全部声部。关闭页面释放材质、几何、纹理、事件监听和 AudioContext。
- 手机赛车两指：左侧转向 / 右侧油门、刹车、加速；加速键同时给油。FPS 两指：左摇杆移动，右拇指按住开火并拖动瞄准；独立瞄准区可不开火观察。
- 沿用项目词库，可选“顺便学词”，只在完成一圈/中继时出现，不暂停操作或强制问答。
