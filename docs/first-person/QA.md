# First Light · 实机验收

2026-09-06，macOS / Intel Core i7-9750H，Codex 内置 Browser。只使用一个运行中的测试 iframe，没有启动无头 Chrome。手机结果来自浏览器触屏与尺寸模拟，**不是实体 iPhone / Android 验收**。

## 执行范围

- Node：`tests/first-person.test.mjs` 覆盖 18 项新游戏规则；同时执行 moon-flow、moon-rig、moonblade、fury-combat 的已有回归，**108 / 108 通过**。
- 桌面输入：赛车 12 项、FPS 15 项；移动端输入：赛车 15 项、FPS 21 项，均通过。新增一项逐个检测动作按钮是否相互遮挡。
- 浏览器控制器通过正式页面键盘、鼠标和多指 PointerEvent 驱动，不写入世界状态、不传送、不加生命。只读诊断用于计算路线与读取结果。控制器具有精确瞄准和路线信息，因此通关速度不是普通玩家预计时长。
- Node 的三条赛道均可用方向 / 油门 / 刹车完成两圈；浏览器另跑完整海岸赛道。
- 射击标准难度：完成三座中继，消灭 16 个防御单位，实际游戏时间 36.82 秒；不是跳过战斗或直接设置通关状态。

## 本轮发现并修复

- 道路三角形朝向错误导致路面不可见；修正绕序及法线。
- 地面改成连续高度场，树木与赛道按同一个高度源放置；道路、标线和装饰有稳定间距。
- 原先按圆形判断赛车接触，会提前撞到相邻车道。现在按车身纵横尺寸与朝向分离；用相对接近速度区别轻擦与重撞，并限制 AI 弯前速度。
- 键盘满舵按速度限制侧向转动，避免中速时一按方向就甩过大角度；响应仍在下一模拟步生效。
- 跨起点需要实际穿越，不能在起点前提前记圈。回正只恢复当前位置，不跳检查门。
- 暂停后的旧触点会占住摇杆；清除内部 pointer ID。右手抬起不再释放左手移动；开火键可以同时拖动瞄准。
- 手机横屏菜单从居中的长卡片改成两列，390×844 竖屏和 844×390 横屏均无横向溢出，开始按钮可见。
- 触屏小按钮移除桌面 padding，避免“换弹 / 跳跃”等文字竖向换行。
- 开火按键独占较宽的网格列，跳跃与开火之间留出间隙；所有动作按钮的实际矩形互不重叠。
- 动态 InstancedMesh 使用稳定的可见性设置，避免子弹沿用初始包围体而突然消失。
- 缓存材质与纹理、合并模型和静态场景几何；降低树冠三角形与均衡模式像素预算。

## 性能与资源

1280×720 CSS 游戏画幅，均衡画质，最多保存最后 1200 个真实 RAF 间隔。工作耗时仅测 JavaScript 模拟及渲染提交，不等于 GPU 时间；截图或系统负载会影响帧间隔。数据仅代表这台机器，不承诺所有设备 60 FPS。

- 射击完整路线最后 1200 帧：间隔中位数 **16.7ms**，P95 **18.4ms**；工作耗时中位数 1.8ms，P95 2.7ms。
- 赛车最终两圈：130.45 秒，第 4 名，1 次碰撞；最后 1200 帧间隔中位数 **16.7ms**，P95 **18.3ms**，工作耗时中位数 1.2ms、P95 1.6ms。控制器只用油门 / 刹车 / 左右键，没有使用加速。
- 三次开局 / 返回菜单：赛车 geometry 47→47、texture 10；FPS geometry 76→74、texture 13，没有持续增长。
- 暂停、返回菜单后：RAF=false、AudioContext=suspended、voices=0；暂停期间世界时间不前进。页面失焦/隐藏也走同一停止路径。
- 不采用只有 5–7 帧、包含首帧着色器编译的短回归统计作为流畅性证明。

## 画面与发布

合集两张新封面均为正式游戏的实际截图，未用 imagegen 伪造游戏画面。赛车截图仅裁掉顶部测试工具栏、等比压缩成 WebP；原始 PNG 保留。imagegen 仅用于进入真实场景的天空 / 环境与混凝土纹理；Blender 用于五类原创建模。

浏览器测试入口：`/tests/first-person-browser.html`。完成后使用“停止并释放”，关闭测试页；线上保留的游戏页停在菜单，不持续渲染或发声。

发布资源版本为 `20260906-firstlight-r1`。发现内置预览会保留相同 URL 的旧模块 / 样式后，使用独立版本 URL 重新验收，避免把缓存旧画面当成最终构建。

这些验收验证输入、规则、完整流程及基本性能，不等同于玩家调研，也不宣称达到商业大作的内容规模。
