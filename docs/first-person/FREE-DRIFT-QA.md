# 自由漂移 · 2026-09-12

版本 `20260912-freedrift-r1`。目标是解开实际操控限制，并让轮迹体现真实运动；不是给旧模型叠加两条交叉线。仍是本项目原创的街机模型，不声称复原了 Nexon 私有物理参数。

## 原因和修改

1. 旧版持续叠加起漂侧的转动力，即使按住 Shift 全力反打，也抵不过这股力。现在当前方向输入直接控制转动，车头角、角速度、行进方向分别连续计算；可以穿过回正，继续向另一侧甩尾。
2. 旧版将行进方向指数贴近车头，间接限制最大侧滑角。现在采用有上限的侧向轮胎力，按车身纵向速度调节转向能力，保留横向动量。长按可以漂过 90°，过度转向会掉速；不是免费的大角度高速转弯。
3. 松漂不再在 0.85 秒后强制恢复抓地。断位采用带角速度阻尼的回正，未回正时保持连续恢复，避免侧滑中途突然切换。跨过零度后再断位也按当前真实侧滑方向判断，不沿用起漂侧限制。
4. 旧胎痕是定时摆放的短平面，朝向还用了行进方向。新胎痕连接每个后轮的真实接地点；两条路径独立，连续共用端点并贴合路面高度。深漂自然交叉，轻漂不强制交叉；碰撞、回正重置不会跨地图连线。
5. 短漂的小喷基础充能门槛由 0.12 调为 0.08，保留最小漂移时长、实际侧滑角、每段一次的条件。修复转向修正后约 0.2 秒的有效轻漂偶尔积不出小喷的问题；不是放开一帧乱点刷喷。
6. 新增独立的宽阔自由漂移场，比赛三条赛道不加宽。默认菜单仍是竞速模式；自由场无对手、无圈数上限，显示实际侧滑角。

## 验证方法

```sh
node --test tests/*.test.mjs
python3 -m http.server 4174 --bind 127.0.0.1
```

浏览器入口 `/tests/apex-rally-browser.html`：通过真实键盘 / PointerEvent 输入适配器发送操作；不赋值位置、速度、车头、道具或计时。新增“大角度 / 交叉胎痕”检查左右深漂、实际后轮路径线段相交、无碰撞干预、持续 Shift 下反打与退出释放。

自动测试覆盖：大角度左右对称、120ms 内反转转动方向、连续角位移、轻漂不交叉、松方向不受隐藏扭力、恢复不被计时器中断、真实比赛和自由场、双喷 / 三连喷及一帧抖动、轮迹共用端点 / 贴地 / 重置断开 / 固定容量。

测试调整保留原因：短漂与深漂轨迹比较从 0.6 秒延长到 0.9 秒，给行进方向差异显现时间；断位检查改为 0.1 秒响应加 0.18 秒稳定，避免恰好比较两个零附近的过冲。双喷 / 连喷的短按序列略缩短以匹配更自由的车头；不放宽真实道路、碰撞或完成次数的断言。另增加左右各 1–4 帧实际转向历史，防止只在一个精准初始角速度下通过。

## 资源约束

胎痕只用一个 Mesh 和固定的 1024 段环形缓冲，顶点和时间戳合计 96 KiB；不为每一段新建网格。GPU 按游戏时间淡出，8 秒寿命，不开额外 RAF。保留原有分辨率、120Hz 固定模拟与显示插值。暂停、菜单和后台仍停止游戏 RAF 及音频。

## 实机记录

Codex 内置 Browser；触屏为尺寸及多点触控模拟，不冒充实体手机测试。下列帧工作时间指 JavaScript 模拟和渲染提交，不是 GPU 时间。

- 深漂初测：左右最大侧滑约 136° / 138°，各有一次真实左右后轮路径相交；保持 Shift 反打，120ms 内角速度改变符号。后续扩大检查范围，不能只在深漂峰值检查未出路面。
- 桌面技巧验证 8 项通过；手机横屏 844×390，双喷、三连喷、断位、自动油门下双指漂移和独立小喷共 11 项通过。
- 全仓规则和流程测试包含三赛道 × 竞速 / 道具，共六场正常输入的完整两圈模拟均完赛（111.43–133.11 秒，18–26 次小喷）。自动控制器能读取精确赛道，成绩不代表玩家难度。
- 桌面实跑海岸道具赛 **117.33 秒完成两圈**，第 2 名；20 次小喷、8 次氮气、9 个补给、4 次命中、4 次擦碰。默认游戏区 1164×964，最后 1200 帧间隔中位数 **16.7ms**、P95 **17.6ms**；模拟与渲染提交中位数 **3.2ms**、P95 **4.7ms**，未同时运行 Node 压力回归。
- 竖屏 390×720（游戏区 390×680）通过全部 14 项操作 / 布局 / 释放检查；8 次重开几何数 **153→153**、纹理 **6→6**。比赛与手机测试结束后 RAF=false、音频 suspended、voices=0；没有浏览器错误或警告。
- 横屏首次资源检查在循环重开阶段出现一次等待超时，不能把那次算通过；触屏动作与布局断言已通过。竖屏完整循环及横屏后续复查分别记录。
- 横屏 844×390 复查 **14 / 14 项通过**；8 次重开几何 **231→231**、纹理 **6→6**，结束后 RAF=false、音频 suspended、voices=0。
- 完赛截图发现暂停 / 结算仍沿用旧暗底，与新深色标题叠加成描边状低对比文字；统一为奶油浅底，移除标题重影。
- 初次浏览器短漂检查发现一次未积出小喷，已保留问题记录并修正门槛、增加初始转向历史回归；不以重跑一次通过代替修复。
- 补查发现深漂后长反打会碰到初版练习场边缘，从而中止漂移；练习场由 100m 拓宽至 180m，正式赛道不变。断言扩展到整个反打与换向断位过程，要求零碰撞、未出路面且仍在有效漂移，不能把碰撞后的角度变化算成正确反打。
- 最终全仓 **259 / 259 项通过**；浏览器扩展后的自由漂移 **13 / 13 项通过**。左右峰值约 137° / 138°，分别真实交叉一次；全程未出路面或碰撞，反打后侧滑连续换向，随后断位有效；结束后 RAF=false、音频 suspended、voices=0。
