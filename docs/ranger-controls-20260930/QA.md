# Word Ranger · 操作与平台路线修整

2026-09-30，基于 `7a65387`。本轮只改 Word Ranger，保留最近的 Echo / Moonblade 视觉更新。未推送、未部署。

## 改动

- **主动下落**：单向平台上按 S / 向下摇杆 + 跳跃，可切回下层路线。只忽略起跳平台，不会同时穿透下层平台；长按不会连续坠落。实体地面仍正常起跳。附轻量下落音效与操作提示。
- **低顶净空**：蹲下或滑铲结束时检查站立空间；头顶有实体障碍则继续蹲姿，离开后自动站起，避免受击框伸入天花板。
- **帧间短按**：保留射击、跳跃、手雷、滑铲的输入边沿，直到物理步消费，减少低帧率时轻点丢失；暂停、失焦、返回菜单清除待处理输入。
- **蹲射瞄准**：鼠标瞄准与引擎枪肩锚点一致，修正蹲姿按站姿高度计算导致的弹道偏差。
