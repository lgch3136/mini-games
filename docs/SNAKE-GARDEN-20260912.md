# 字母花园：移动与玩法重做验收

版本：`20260912-garden-r4`。范围仅限 `english-word-snake/`、游戏大厅对应卡片和新增验收文件。

## 旧版问题及修复

1. 旧版先移动逻辑格，再把前一格插到当前格，画面整整落后一格。新引擎 120 Hz 固定更新，当前格内进度立即显示，渲染包含余下帧时间。
2. 旧版每节身体各自插值，转弯时斜切、压缩。新蛇身沿蛇头经过的同一条连续折线采样，穿边界使用邻接副本裁剪，没有横跨场地的大对角线。
3. 旧版完成单词冻结 0.55 秒，并把插值瞬间拉到终点。新版完成不停止、不断开位置，词条确认与奖励在移动中发生。
4. 正在离开的尾格被误判自撞；已修复。顺序未到的字母现在是可以穿过的预览，不再因为撞上未来字母被扣命。
5. 旧版每次吃字母增长三节、遇墙停在原地反复受伤。新版每字母一节、完成缩短三节、有长度上限；经典模式护栏沿边救回。
6. 旧版大面积渐变、滤镜、格子每帧重复绘制。新版静态花园缓存，有限粒子与音频节点，暂停/选单不运行 RAF 或音乐调度。
7. 手机旧版每次滑动只能转一个弯。新版持续跟踪同一个手势，方向与冲刺分别支持独立指针，取消/失焦释放输入。

## 可玩性调整

- 独立五档速度，不再因为选择高级词库就自动加速。
- 长按冲刺、松开缓回常速，能量收支明确，冲刺吃字母获得双倍分。
- 连续采集升级倍率；每三轮出现可选金果路线，收齐回血；无失误完整词奖励护盾。
- 字母路线按较近的自由格安排，只放目标单词字母；语法选项全文显示在 HUD，用 A/B/C/D 对应果实。
- 三套安静、清晰的花园配色，新的角色、收集光圈、粒子、HUD 弹性反馈与原创五声音阶配乐。
- 网格开局按窗口选择，之后只做等比例显示。大幅调整尺寸先暂停，横屏使用紧凑 HUD 与控制条。

## 验收方法与观测

- 全库 `node --test tests/*.test.mjs`：304 / 304 通过。其中贪吃蛇新增 32 项规则与输入测试。
- 纯规则验收在 24×16、16×18、14×22、32×12 场地，以及语法模式下，用方向输入完成至少 20 轮；另测短横屏、尾格、连续转向、成长、冲刺、暂停、提示、诊断数据隔离。
- 内置 Browser 实际页面以普通 KeyboardEvent / PointerEvent 驱动，不修改血量、位置或直接调用采集。
- 桌面拼词 65 秒完成 9 轮，完整特效运行过 28 个并存粒子；工作耗时 P95 约 0.8 ms，帧间隔 P95 17.5 ms；最后 900 帧没有超过 34 ms 的帧。
- 桌面语法 40 秒完成 21 轮，完整特效运行过 42 个并存粒子；工作耗时 P95 约 0.7 ms，最大约 4.9 ms；最后 900 帧没有超过 34 ms 的帧。
- 手机尺寸（390×844 外层浏览器）拼词 65 秒完成 15 轮；有 5 次真实碰撞，结束剩 1 心，未隐藏碰撞或伪造无伤。工作耗时 P95 约 0.7 ms，最大 5 ms；最后 900 帧没有超过 34 ms 的帧。
- 手机连续滑动、第二指冲刺、pointercancel、方向按钮、键盘 repeat 过滤、失焦暂停与返回选单均通过。
- 最终 r4 候选再次运行 65 秒（游戏视口 390×779）：13 轮、2 次碰撞、结束 3 心；完整动效开启，工作耗时 P95 0.9 ms、最大 5.3 ms；暂停/恢复/退出和全部 11 项运行检查通过。
- 额外人工观察 390×844、320×568、844×390 的游戏画面；修正了果实文字过小、横屏控制区域溢出与旋转时继续走动的问题。
- 暂停、恢复、返回选单后，RAF、音乐定时器、活动音频节点和 UI 动画数按预期归零；暂停世界时间不再推进。

以上性能是本机内置 Browser 的观测，手机尺寸模拟不是手机硬件实测。自动驾驶能验证操作链路与稳定性，不代表主观趣味性已经完美，也不是宣称没有碰撞或所有设备都能稳定 120 帧。

旧版 `game.js` 被新模块替代，完整旧实现仍保留在 Git 历史中，可正常回退。
